## 📝 글쓰기용

### 🎯 만능 글쓰기 프롬프트 (스니펫 강화판)

```
"[키워드]"로 블로그 글을 써줘.

[구조 — Heading 순서 엄수]
- H1: 글 제목 1개만 (60자 이내, 키워드 맨 앞 배치, 동사로 끝나지 않게)
  공식: 혜택 + 숫자 + 형용사 + 타깃 키워드
  예) "클릭을 부르는 7가지 쉬운 [키워드] 활용법"
- 도입부: 독자의 문제점 + "이 글에서 해결됩니다" 약속 (200자)
- H2 섹션 4~6개 (각 500자 내외)
- H2 → H3 → H4 순서 지킬 것 (H1 → H3 금지, 순서 빼먹기 금지)
- 각 섹션마다 표 / 넘버링 / 불릿 / 인용구 중 2개 이상 필수 사용
- FAQ 3~5개 (Q&A 형식, 질문은 H3)
- 결론: 핵심 3줄 요약 + CTA

[스니펫 달성 요소 — 7개 중 최소 4개 포함 필수]
1. ✅ 넘버링 (순서 있는 단계 정리)
2. ✅ 불릿 리스트 (순서 없는 항목 나열)
3. ✅ 비교/정리 테이블 (가로 3열 이상 권장)
4. ✅ 질문과 답변 형식 (FAQ 외 본문에도 1~2개)
5. ✅ 논리적 구획(section) 구조
6. ✅ 인용구 사용 (핵심 문장 강조용 1~2개)
7. ✅ 양질의 정보 (직접 경험, 수치, 출처 포함)

[SEO 키워드 배치 — 스터핑 절대 금지]
- 본문 키워드 사용: 3~5회만 (절대 초과 금지)
- 같은 키워드 반복 시 LSI 키워드(유의어/연관어)로 분산
  예) "맥북" → "노트북", "애플 노트북", "M3 모델", "맥북에어"
- 키워드 분산 위치:
  · Title 태그 (H1)
  · 메타 디스크립션
  · 이미지 alt 텍스트
  · URL slug
  · 첫 문단 100자 이내 1회
  · H2 중 1개
  · 결론 마지막 문단
- 동일 링크 텍스트(앵커) 반복 금지

[메타 디스크립션]
- 155자 이내 1줄 별도 제공
- 페이지 핵심 요약 + 클릭 유도
- 키워드 1회만 자연스럽게 포함
- 모든 글마다 고유하게 작성

[Heading 순서 체크]
- H1: 정확히 1개
- H2: 무제한
- H3: H2 하위에만, H4: H3 하위에만
- ❌ H1 → H3 건너뛰기 금지
- ❌ H4 → H2 역행 금지

[톤앤매너]
- 전문적이지만 친근한 해요체
- 어려운 용어는 괄호 안에 쉬운 설명 추가
- 구체적 숫자/데이터 포함 (예: "약 2배" → "1.8배")
- 한 문단 3줄 이내 (모바일 가독성)
- 글자 수: 2,500~4,000자

[내부 링크(인링크) 삽입 위치 — 최소 5곳 표시]
- [내부 링크: 관련 글 제목] 형태로 표시
- 앵커 텍스트는 매번 다르게

[피처드 스니펫 노리기]
- H2 중 1개는 반드시 "~하는 방법", "~란 무엇인가", "~ 차이"
  같은 질문형으로 작성
- 그 H2 바로 아래에 40~60자 단답형 정의 문장 1개 배치
- 그다음 단계/목록/표로 상세 설명
```

### 💧 사람 냄새 추가 (E-E-A-T)

```
위 글에 다음을 자연스럽게 추가해줘:

1. 개인적인 사용 경험 1~2개 (실제 사용 시간, 상황 묘사 포함)
2. "솔직히", "개인적으로는", "써보니까" 같은 구어체 3~5곳
3. 독자에게 말 거는 문장 (예: "이런 경험 있으신가요?")
4. 반전이나 의외의 포인트 1개 (단점 솔직 공개 등)
5. 짧은 실패담 1개 (신뢰감 상승)
6. [개인 경험 삽입], [스크린샷 삽입] 플레이스홀더 표시

E-E-A-T 강화 포인트:
- Experience(경험): 직접 써본 시간/횟수 명시
- Expertise(전문성): 비교 데이터, 수치 근거
- Authoritativeness(권위): 공식 자료 출처 1~2개
- Trustworthiness(신뢰): 단점 솔직 공개, 추천 안 하는 대상도 명시
```

### 🛒 제휴 마케팅 글 (강화판)

```
"[제품명]" 리뷰 블로그 글을 써줘.

[필수 요소]
- 솔직한 장단점 (장점 5개 / 단점 3개 이상)
- "추천 대상 / 비추천 대상" 명확히 구분
- 경쟁 제품 비교표 (가로 4열 이상: 제품명/가격/장점/단점)
- 자연스러운 구매 유도 (강매 금지)

[스니펫 노리기]
- "[제품명] 후기" "[제품명] vs [경쟁사]" 형태의 H2 포함
- 비교표는 첫 H2 직후에 배치 (테이블 스니펫 노출 확률 ↑)
- "이런 분께 추천" 섹션은 불릿 리스트로

[금지 표현]
- "100%", "무조건", "최고", "절대"
- "할인", "공짜", "혜택", "쿠폰" 남발
- 같은 키워드 반복 (LSI 키워드로 분산)

[신뢰성 강화]
- 사용 기간 명시 (예: "3개월 사용 후 솔직 후기")
- 실제 사용 사진 위치 [사진 삽입] 플레이스홀더
- 단점 먼저, 장점 나중 배치
```

## 🔍 키워드 분석용

### 경쟁 분석 (강화판)

```
"[키워드]"를 구글에 검색했을 때
상위 5개 글의 장단점을 분석해줘.

각 글에 대해:
- 작성 시점 (오래되었으면 코너스톤으로 역전 가능)
- 글 길이 (2,500자 미만이면 길이로 이기기)
- 다루는 내용
- 빠져 있는 정보 (내가 추가할 부분)
- 사용한 스니펫 요소 (표/리스트/Q&A 유무)
- 내가 이길 수 있는 포인트

추가로:
- 상위 5개 글 중 피처드 스니펫이 있는지
- 있다면 어떤 형식인지 (단락/리스트/표/동영상)
- 없다면 내가 노릴 수 있는 기회
```

### 검색 의도 분석

```
"[키워드]"를 검색하는 사람의 의도를 분석해줘.

1. 주요 검색 의도 (정보형/비교형/구매형/거래형)
2. 검색자가 진짜 알고 싶은 것 3가지
3. 최적의 글 구조 (코너스톤 페이지 가능성 평가)
4. 반드시 포함할 정보
5. 경쟁 글에서 빠져있는 정보
6. LSI 키워드 10개 (본문 분산용 유의어/관련어)
7. 피처드 스니펫 노릴 만한 질문형 키워드 3개
```

```
[스니펫 요소]
- 표 3개 이상 (전체 비교/단계별 가이드/Q&A 정리)
```

```
□ 넘버링

□ 비교/정리 테이블
□ 질문과 답변 형식
□ 인용구
□ 양질의 정보 (수치/출처)
□ 논리적 구획 구조

[피처드 스니펫 노리기]
□ 질문형 H2 ("~하는 방법", "~란?")가 1개 이상 있는가
□ 그 H2 직후 40~60자 단답형 정의 문장이 있는가

[E-E-A-T]
□ 직접 경험이 1~2개 포함되었는가
□ 단점이나 한계도 솔직하게 공개되었는가
□ 구체적 수치/날짜/출처가 있는가

[인링크]
□ 다른 글로의 내부 링크 5개 이상 표시되었는가
□ 앵커 텍스트가 다양한가

부족한 항목이 있으면 한국어로 보고하고
즉시 수정해줘.
```
