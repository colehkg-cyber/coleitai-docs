# Step 4. 관리자 패널 익히기

> **이 단계에서 할 일**
> 블로그 템플릿에 내장된 `/admin` 관리자 패널의 **8가지 메뉴**를 둘러보고, 각 메뉴가 무엇을 하는지 익힙니다.
> 끝나면 "글 발행·키워드 등록·사이트 설정 변경" 모두 코드 안 건드리고 할 수 있습니다.

---

## /admin 접속

브라우저에서:
```
https://my-blog-xxxx.vercel.app/admin
```

비밀번호 입력란 → Step 1에서 정한 `ADMIN_PASSWORD` 입력 → 로그인.

> 💡 비밀번호 잊었으면 Vercel → Settings → Environment Variables 에서 확인·변경.

---

## 패널 상단 메뉴 한눈에

```
[커스텀] [설정 가이드] [전문 지식] [키워드] [글 관리] [통계] [사이트 설정]   [+ 새 글 작성]
```

| 메뉴 | 한 줄 설명 |
|---|---|
| 커스텀 | 디자인·로고·색상 (Claude Code로 변경 안내) |
| 설정 가이드 | 5단계 환경변수 상태 점검 |
| 전문 지식 | AI 글쓰기 시스템 프롬프트 + 참고 자료 |
| 키워드 | AI 글 자동 생성용 키워드 등록 |
| 글 관리 | 글 목록·편집·삭제 |
| 통계 | 조회수·트래픽 |
| 사이트 설정 | Favicon·Meta·Unsplash 키 |
| + 새 글 작성 | 글 작성 화면으로 이동 |

---

## 1. 설정 가이드 (Setup Guide)

배포 직후 가장 먼저 확인할 화면. **환경변수 5개 상태**를 점검합니다.

```
✅ 사이트 URL        (NEXT_PUBLIC_SITE_URL)
✅ Turso DB         (TURSO_DATABASE_URL)
✅ DB 토큰          (DATABASE_AUTH_TOKEN)
✅ Gemini API 키    (GEMINI_API_KEY)
✅ Admin 비밀번호    (ADMIN_PASSWORD)
```

5개 모두 초록 동그라미면 정상. 빨간 동그라미가 있으면 Vercel 환경변수 다시 확인.

### 브랜딩 설정 안내
이 화면에서 브랜딩(블로그 이름·설명·로고)을 **클릭으로 바꾸는 건 안 됩니다.** Claude Code에게 한국어로 명령해서 코드를 수정해야 합니다.

```
예) "블로그 이름을 '내 블로그'로 바꿔줘"
```

자세한 디자인 커스텀은 → **[Step 3. 디자인 커스텀](./design-custom.md)**.

## 2. 전문 지식 (Expert Knowledge)

AI가 글을 쓸 때 **항상 따라야 하는 규칙**을 정의하는 곳.

### 시스템 지침 (`system-instruction.md`)
- AI에게 "이런 톤으로, 이런 구조로, 이 정도 길이로 써" 라고 지시하는 글
- 기본값 제공됨 (SEO 블로그 글쓰기 최적화 프롬프트)
- 내 블로그 성격에 맞게 수정 가능

수정 예시:
```
- 톤: 친근한 반말 → 정중한 존댓말
- 길이: 1500자 → 2500자
- 형식: 일반 글 → 리스트형(BEST 10 형태)
```

### 지식 파일 (참고 자료)
- AI가 글 쓸 때 참고할 PDF·문서·링크 업로드
- 예: 내 회사 제품 카탈로그, 업계 가이드라인
- E-E-A-T(전문성·경험·권위·신뢰성) 강화에 도움

## 3. 키워드 (Keywords)

AI 자동 글 생성에 사용할 **키워드 목록**을 관리하는 곳.

### 입력 방법
| 방식 | 사용 |
|---|---|
| 직접 입력 | 쉼표 또는 줄바꿈으로 구분 |
| CSV 업로드 | 엑셀에서 만든 키워드 목록 일괄 업로드 |

### 등록 후 흐름
```
키워드 등록
    ↓
크론잡(자동 스케줄러)이 매일 키워드 1개 픽
    ↓
Gemini가 시스템 지침 + 지식 파일 기반으로 글 작성
    ↓
자동 발행 (또는 임시 저장)
    ↓
통계에 조회수 누적
```

> 💡 키워드 발굴 방법은 → **[Step 6. 황금 키워드 채굴](./keyword-mining.md)**.

## 4. 글 관리 (Post Management)

발행된 모든 글의 목록.

### 표시 정보
| 칼럼 | 내용 |
|---|---|
| 제목 | 글 제목 |
| 발행됨 | Yes/No (Draft 여부) |
| 조회수 | 누적 방문자 |
| 액션 | 보기·링크 복사·편집·삭제 |

### 액션 버튼
- **보기**: 실제 블로그에서 어떻게 보이는지 새 탭에서 확인
- **링크**: 글 URL 복사 (SNS 공유용)
- **편집**: 글 내용 수정 화면으로
- **삭제**: 글 영구 삭제 (GitHub·DB 모두)

---

## 5. 새 글 작성 (+ New Post)

우측 상단 파란 버튼 → 글 작성 화면.

### 입력 필드
- 제목
- 카테고리 / 태그
- 대표 이미지 (또는 Unsplash 자동 선택)
- 본문 (마크다운 또는 에디터)
- 발행 상태 (Draft / Published)

### AI 어시스트 (옵션)
- "키워드만 입력 → AI가 초안 생성" 기능 내장
- 직접 쓸 수도 있음

발행 후 → 약 1~2분 뒤 블로그 메인에 노출.

## 6. 통계 (Statistics)

블로그 트래픽 한눈에:
- 일별/주별 조회수 추이
- 인기 글 TOP 10
- 유입 경로 (검색·직접·SNS)

## 7. 사이트 설정 (Site Settings)

블로그 외관·메타 정보를 변경하는 곳.

| 항목 | 무엇 | 예시 |
|---|---|---|
| Favicon | 브라우저 탭 아이콘 | 작은 로고 이미지 업로드 |
| Unsplash Access Key | AI가 글 썸네일 자동 선택 시 사용 | unsplash.com 무료 발급 |
| 기본 OG 이미지 | Unsplash 실패 시 대체 이미지 | `default-og.png` (1200×630) |
| Meta Description | 구글 검색 결과에 노출되는 한 줄 설명 | "강남 카페 추천 블로그" |

### Unsplash Access Key 발급 (선택)
1. [`unsplash.com/developers`](https://unsplash.com/developers) 접속
2. 무료 가입 → New Application
3. Access Key 복사 → 이 화면에 붙여넣기 → 저장

이후 글 작성 시 키워드 기반으로 적절한 무료 이미지 자동 선택.

### 썸네일 → OG 이미지 자동 흐름
1. Unsplash에서 키워드 매칭 이미지 1장 가져오기
2. **자동 1200×630 리사이징** (Vercel Image Optimization)
3. `<meta property="og:image">` 자동 삽입 → 카톡·페북·트위터 공유 시 미리보기 정상 노출

### Fallback (대체) 이미지 — 필수 준비
다음 경우에 사이트 기본 이미지 `default-og.png`가 자동 사용됩니다:
- Unsplash Access Key 미발급
- 무료 할당량(시간당 50회) 초과
- 키워드에 매칭되는 이미지 없음
- 네트워크 오류

#### 기본 이미지 준비 방법
1. [Canva](https://canva.com) → 사용자 지정 사이즈 → **1200 × 630 px**
2. 사이트 로고 + 슬로건 한 줄 디자인 (5분)
3. PNG 또는 JPG로 다운로드 (1MB 이내)
4. 파일명을 `default-og.png` 로 저장
5. Claude Code에 다음 한 줄:
   ```
   default-og.png 파일을 public 폴더에 추가하고
   OG 이미지 fallback 로직이 이 파일을 가리키도록 해줘.
   ```

> ⚠️ 이 fallback 이미지를 준비 안 하면, Unsplash 호출이 실패한 글은 **카톡/페북 공유 시 미리보기 이미지가 빈 칸**으로 보입니다. 클릭률 30~40% 손실.

## 자주 묻는 질문

**Q. /admin 접속 시 "401 Unauthorized".**
- ADMIN_PASSWORD 오타 확인. 또는 Vercel 환경변수 재설정 후 Redeploy.

**Q. AI가 글을 안 만들어요.**
- Gemini API 키 환경변수 확인 (`/admin/setup` 페이지 → 5번째 항목 초록).
- 또는 무료 한도 초과. 24시간 뒤 재시도.

**Q. 글이 안 보여요. (404)**
- 발행 상태 Draft → Published 로 변경. Vercel 재배포 1~2분 대기.

**Q. 외부에서 /admin 접속해도 되나요?**
- 가능. 단 ADMIN_PASSWORD 안전한 것 사용. 영문+숫자+특수문자 12자 이상.

**Q. 비밀번호를 다른 사람에게 알려주면?**
- 그 사람도 글 작성·삭제 가능. **공유 금지.**
