# Step 7. AI 글쓰기 실전 (크론잡 자동 발행)

> **이 단계에서 할 일**
> Gemini API + 크론잡(자동 스케줄러)으로 **잠자는 동안 글이 자동으로 발행되는 시스템**을 켭니다.
> 끝나면 매일/매주 키워드 1개씩 골라 AI가 알아서 글 쓰고, 알아서 발행합니다.

---

## 두 가지 글쓰기 방식

| 방식 | 누가 글 쓰나 | 사람 손길 | 빈도 |
|---|---|---|---|
| **자동 발행** ⭐ | Gemini + 크론잡 | 키워드만 등록 | 매일·매주 |
| **수동 발행** | 내가 Claude 프롬프트 | 본인이 직접 검수·편집 | 글 쓰고 싶을 때 |

> 💡 이 가이드는 **자동 발행** 위주. 수동은 마지막에 보너스로.

---

## 크론잡이 뭐예요?

> 👉 **"정해진 시간에 자동으로 어떤 작업을 실행시키는 알람 시스템."**

비유: 자명종.
- 매일 아침 7시 → 자명종이 울림
- 우리 블로그도: 매일 아침 9시 → 크론잡이 "Gemini야, 글 하나 써서 발행해" 실행

### Vercel Cron Jobs
Vercel에 내장된 무료 기능. 우리 템플릿은 이걸 사용.

```
vercel.json 안에 스케줄 설정
  ↓
Vercel이 매일·매시간 정해진 시각에
  ↓
블로그의 /api/cron 엔드포인트를 자동 호출
  ↓
거기서 Gemini로 글 생성·발행
```

---

## 자동 발행 작동 흐름

```
   ┌─────────────────────────────────┐
   │  사람이 한 일 (1회 세팅)         │
   │  - 키워드 등록 (/admin)         │
   │  - 시스템 지침 작성 (/admin)    │
   │  - 지식 파일 업로드 (선택)      │
   └─────────────────┬───────────────┘
                     ↓
   ─────────── 이후 자동 ───────────
                     ↓
   매일 정해진 시각 (예: 오전 9시)
                     ↓
   ┌─────────────────────────────────┐
   │  Vercel Cron 발동                │
   └─────────────────┬───────────────┘
                     ↓
   ┌─────────────────────────────────┐
   │  1. DB에서 미발행 키워드 1개 픽   │
   └─────────────────┬───────────────┘
                     ↓
   ┌─────────────────────────────────┐
   │  2. 시스템 지침 + 지식 파일 로드 │
   └─────────────────┬───────────────┘
                     ↓
   ┌─────────────────────────────────┐
   │  3. Gemini API 호출 (글 생성)    │
   └─────────────────┬───────────────┘
                     ↓
   ┌─────────────────────────────────┐
   │  4. Unsplash로 썸네일 자동 선택  │
   └─────────────────┬───────────────┘
                     ↓
   ┌─────────────────────────────────┐
   │  5. Turso DB에 글 저장 + 발행    │
   └─────────────────┬───────────────┘
                     ↓
   ┌─────────────────────────────────┐
   │  6. 블로그에 즉시 노출            │
   └─────────────────────────────────┘
```

**한 문장 요약**: 키워드만 미리 채워두면 → 매일 1편씩 AI가 자동으로 발행.

## 1. 키워드 등록 (10분)

`/admin` → **키워드** 메뉴.

### 입력 방법
| 방식 | 권장 시점 |
|---|---|
| 직접 입력 (쉼표·줄바꿈 구분) | 5~10개 빠르게 |
| CSV 업로드 | 50개 이상 한 번에 |

예시 입력:
```
강남 카페 추천
홍대 디저트 가게
이태원 와인바
판교 브런치
성수동 베이커리
```

> 💡 **한 달 분량 미리 채우기 추천**: 30개 등록 → 매일 1개씩 자동 발행 → 1달 운영.

### 키워드 채굴 방법
→ **[Step 6. 황금 키워드 채굴](./keyword-mining.md)** 참고. 황금 키워드 30개를 먼저 확보하고 등록.

## 2. 시스템 지침 작성 (10분, 1회만)

`/admin` → **전문 지식** → **시스템 지침**.

AI가 글 쓸 때 **매번 따르는 규칙**. 한 번만 잘 작성하면 끝.

### 권장 템플릿

```markdown
# SEO 블로그 글쓰기 시스템 지침

## 페르소나
당신은 10년 차 [내 분야] 전문 블로거입니다.
독자는 [타겟층]이며, 친근하고 실용적인 정보를 원합니다.

## 글 구조
- H1: 키워드 포함, 60자 이내
- 도입부: 독자 문제 짚기 + 해결 약속 (200자)
- H2 섹션: 4~6개, 각 500~700자
- 표·리스트·코드블록 중 하나 이상 매 섹션 포함
- FAQ 3~5개 (구조화 데이터용)
- 결론: 핵심 3줄 + CTA

## SEO 규칙
- 키워드를 H1·도입부·H2 1개·결론에 자연스럽게 포함
- 메타 디스크립션 (155자 이내) 마지막에 별도 제공
- 내부 링크 위치 2곳 표시

## 톤
- 친근한 해요체
- 어려운 용어는 괄호 안 쉬운 설명
- 구체적 숫자·데이터 포함

## 글자 수
2,500~4,000자
```

이걸 한 번 저장하면 → 이후 모든 글이 이 규칙으로 생성.

## 3. 지식 파일 업로드 (선택, 5분)

`/admin` → **전문 지식** → **지식 파일**.

내가 가진 자료(PDF·문서·링크)를 업로드. AI가 글 쓸 때 참고함.

예시:
- 내 회사 제품 카탈로그 PDF
- 업계 통계 자료
- 자주 인용할 외부 출처 링크 모음

### E-E-A-T (구글이 좋아하는 4가지)
- **E**xperience (경험)
- **E**xpertise (전문성)
- **A**uthority (권위)
- **T**rust (신뢰)

지식 파일이 풍부할수록 → 글에 전문성·신뢰성 자동 반영 → 구글 평가↑.

## 4. 크론잡 스케줄 설정

블로그 코드 폴더의 `vercel.json` 파일에서 발행 주기를 조절합니다.

### 기본 스케줄 (매일 오전 9시 1편)
```json
{
  "crons": [
    {
      "path": "/api/cron/generate-post",
      "schedule": "0 9 * * *"
    }
  ]
}
```

### 스케줄 cheat sheet
| 빈도 | 표현식 | 의미 |
|---|---|---|
| 매일 오전 9시 | `0 9 * * *` | 매일 1편 |
| 매일 9시·21시 | `0 9,21 * * *` | 매일 2편 |
| 평일만 9시 | `0 9 * * 1-5` | 주 5편 |
| 매주 월요일 9시 | `0 9 * * 1` | 주 1편 |
| 매시간 | `0 * * * *` | 시간당 1편 (테스트용) |

### 변경 방법
Claude Code에게:
```
vercel.json의 cron 스케줄을 매일 오전 9시·오후 9시로 바꾸고
git push 해줘.
```

Vercel이 자동 재배포 → 다음 시각부터 새 스케줄로 동작.

> ⚠️ **Vercel Hobby 무료 플랜 제한**: cron 최대 2개. 더 자주 발행하려면 Pro 필요.

## 5. 첫 자동 발행 확인

세팅을 마쳤다면 첫 자동 발행 시각까지 기다리거나, **수동으로 1회 트리거**.

### 수동 트리거
`/admin` → **글 관리** → **"수동 생성"** 버튼 (있는 경우) → 클릭.

또는 브라우저에서:
```
https://my-blog.vercel.app/api/cron/generate-post?key=ADMIN_PASSWORD
```

(템플릿 버전에 따라 다름. `/admin/setup` 화면 안내 참고.)

### 발행 확인
1. `/admin` → **글 관리** → 최상단에 새 글
2. 블로그 메인 페이지 → 새 글 노출
3. **통계** → 1~2시간 뒤 첫 조회수

---

## 발행된 글 검수 (사람 손길 ⭐)

AI 자동 발행 글은 **그대로 두면 안 됩니다.** 검수 필수.

### 매일 5분 루틴
```
1. /admin → 글 관리 → 오늘 발행된 글 클릭
2. 본문 통독 (3분)
3. 다음 5가지 점검·추가:
   ☐ 사실 오류 (Gemini가 가끔 틀림)
   ☐ 어색한 한국어 표현
   ☐ 내 경험·의견 1~2 문단 추가
   ☐ 스크린샷·이미지 1장 이상 추가
   ☐ 내부 링크 [내부 링크] 자리 2개 채우기
4. 저장 → 자동 재배포
```

### 왜 검수가 핵심인가?
구글은 **"AI 글이라서"** 가 아니라 **"가치 없는 글이라서"** 페널티를 줍니다.
사람 경험·의견·이미지가 들어가면 → AI 글도 충분히 상위 노출 가능.

## 추천 운영 시나리오

### 시나리오 A. 풀 자동 (게으른 사장님)
- 키워드 30개 등록
- 시스템 지침 1회 설정
- `vercel.json` 매일 1편
- **검수 안 함** (그대로 발행)
- 결과: 빠른 양 확보. 단기 트래픽 성장. 다만 일부 글 품질 낮을 수 있음.

### 시나리오 B. 반 자동 (균형) ⭐ 추천
- 키워드 30개 등록
- 시스템 지침 + 지식 파일 풍부
- 매일 1편 자동 발행
- **매일 5분 검수**로 사람 손길 추가
- 결과: 양과 질 모두. 안정적 트래픽 성장.

### 시나리오 C. 자동 + 수동 병행 (퀄리티 우선)
- 자동 발행: 주 3편 (월·수·금)
- 수동 발행: 주 1편 (Claude 프롬프트로 직접, 매우 디테일하게)
- 결과: 자동 글이 롱테일, 수동 글이 빅 키워드 공략.

## 자주 묻는 질문

**Q. 크론잡이 안 돌아가요.**
- Vercel Dashboard → 프로젝트 → **Crons** 탭 → 실행 이력 확인.
- 실패했다면 로그 보고 환경변수 다시 점검.

**Q. 매일 같은 시간에 발행하면 구글이 의심 안 하나요?**
- 사람도 매일 같은 시간에 출근하듯 발행하는 사람 많음. 문제 없음.
- 정 걱정되면 `0 9-18/3 * * *` 같이 시간 분산.

**Q. Gemini 무료 한도 초과되면?**
- 하루 1,500회 = 1일 1글에는 차고 넘침. 실제로는 안 넘침.
- 넘었다는 알림 받으면 24시간 뒤 자동 정상화.

**Q. AI 글이 표절 위험은?**
- LLM은 새로 작성. 표절 X.
- 다만 검수 시 사실 확인은 본인 책임.

**Q. 같은 키워드 두 번 발행되나요?**
- 시스템이 "발행됨" 표시로 관리. 한 번 발행된 키워드는 다시 안 씀.

**Q. 발행 글 자동 SNS 공유는?**
- 별도 자동화 필요 (Zapier, IFTTT 등). 추후 확장 가능.
