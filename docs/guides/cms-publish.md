# Step 4. Decap CMS로 글 발행 사이클

> **이 단계에서 할 일**
> `/admin` 페이지에 접속해서 워드프레스처럼 글을 작성·발행하고, 그 글이 어떻게 GitHub·Vercel을 거쳐 블로그에 실시간으로 반영되는지 확인합니다.

---

## 글 발행 한 사이클

```
1. /admin 접속
2. "New Post" 클릭
3. 제목·본문·이미지 입력
4. "Publish" 클릭
        ↓
5. (자동) GitHub에 .md 파일 추가
        ↓
6. (자동) Vercel 빌드·재배포
        ↓
7. 1~2분 후 내 블로그에 글 공개
```

손이 닿는 건 1~4번까지. 5~7번은 전부 자동.

---

## 1. /admin 페이지 접속

브라우저에서:
```
https://my-blog-xxxx.vercel.app/admin
```

처음 접속하면 **"Login with GitHub"** 버튼.

### GitHub OAuth 로그인 (1회)
1. **"Login with GitHub"** 클릭
2. GitHub 로그인 (이미 로그인되어 있으면 자동)
3. 권한 허용 → Decap CMS가 내 GitHub에 글 파일을 작성할 권한을 받음
4. /admin 메인 화면 진입

> 💡 처음 한 번만. 이후엔 자동 로그인.

---

## 2. /admin 화면 구조

```
┌────────────────────────────────────────┐
│  Decap CMS                             │
├──────────┬─────────────────────────────┤
│          │                             │
│ Sidebar  │   글 목록 / 작성 영역        │
│          │                             │
│ - 글     │                             │
│ - 페이지 │                             │
│ - 설정   │                             │
│          │                             │
└──────────┴─────────────────────────────┘
```

왼쪽: 카테고리 / 오른쪽: 글 목록·편집기.

---

## 3. 새 글 작성

### 기본 정보 입력
1. 좌측 **"글"** 카테고리 클릭
2. 우측 상단 **"New Post"** (또는 "+") 클릭
3. 다음 항목 입력:

| 필드 | 예시 |
|---|---|
| 제목 | "강남 카페 추천 BEST 5" |
| 발행일 | 오늘 날짜 (자동) |
| 카테고리 | "맛집" (드롭다운) |
| 태그 | `강남, 카페, 디저트` (쉼표 구분) |
| 대표 이미지 | 드래그&드롭으로 업로드 |
| 본문 | 마크다운 또는 리치 에디터 |

### 본문 입력 방법

| 방식 | 사용 |
|---|---|
| **리치 에디터** | 워드처럼 버튼으로 굵게·이미지 삽입 |
| **마크다운** | `**굵게**`, `# 제목` 직접 입력 |

둘 중 편한 거 사용.

### 이미지 삽입
- 본문 안에 드래그&드롭 → 자동으로 `static/img/uploads/` 에 저장됨
- 또는 **"Image"** 버튼 → 컴퓨터에서 선택

---

## 4. 미리보기 & 발행

### 미리보기
- 화면 우측 **"Preview"** 탭 → 실제 블로그에 어떻게 보일지 확인
- 모바일 미리보기도 가능

### 발행
1. 화면 우상단 **"Status"** 드롭다운 → **"Published"** 선택
2. 우상단 **"Publish"** 버튼 클릭

> 💡 **임시저장**: Status를 "Draft" 로 두면 발행되지 않고 저장만 됩니다.

---

## 5~7. 자동 발행 과정 (관찰)

발행을 클릭하면 다음이 **자동으로** 일어납니다.

### 5. GitHub에 .md 파일 자동 생성
- 내 GitHub `my-blog` 레포 → `content/posts/` 폴더
- 새로운 파일 추가됨: `2024-05-13-gangnam-cafe.md`
- 커밋 메시지: `Create Post "강남 카페 추천 BEST 5"`

### 6. Vercel 자동 재배포
- Vercel Dashboard → Deployments → 새 배포가 **Building** 상태로 시작
- 1~2분 후 **Ready**

### 7. 블로그에 공개
- `https://my-blog-xxxx.vercel.app` → 메인 페이지 새로고침
- 새 글이 보임!

---

## 글 수정·삭제

### 수정
1. /admin → 좌측 "글" → 수정할 글 클릭
2. 내용 변경 → **"Publish"** → 자동 재배포

### 삭제
1. 글 편집 화면 → 우상단 **"Delete"**
2. 확인 → GitHub에서 자동 삭제 → 재배포 후 사라짐

> 💡 잘못 삭제했어도 GitHub 이력에서 복구 가능.

## 자주 묻는 질문

**Q. /admin 접속 시 "404 Not Found".**
- Vercel 배포가 아직 완료 안 됨. Deployments에서 Ready 확인.
- 또는 `static/admin/index.html` 파일이 없음. 템플릿 다시 확인.

**Q. GitHub 로그인 후 "Failed to authenticate".**
- OAuth 설정 문제. 템플릿 README 참고.
- 일반적으로 GitHub App 권한 재허용으로 해결.

**Q. 이미지 업로드 후 "Failed to commit".**
- 이미지 용량 너무 큼 (10MB 이상). 압축해서 업로드.

**Q. 글 발행했는데 블로그에 안 보임.**
- Vercel 재배포가 완료됐는지 확인 (1~2분 소요).
- 브라우저 강력 새로고침: `Cmd/Ctrl + Shift + R`.

**Q. 모바일에서도 글 쓸 수 있나요?**
- 가능. 모바일 브라우저로 `/admin` 접속. 모든 기능 동작.

## 권장 발행 흐름

매일/매주 글 쓰는 루틴:

```
1. 키워드 채굴로 주제 정함 (Step 6)
2. /admin 접속
3. AI 글쓰기로 초안 생성 (Step 7)
4. 내 경험·정보 추가 (직접 편집)
5. 미리보기 확인
6. Publish 클릭
7. 5분 후 블로그에서 확인
```
