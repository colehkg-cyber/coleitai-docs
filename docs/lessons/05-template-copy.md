# 5강. 템플릿 복사

> **소요 시간**: 5분
> **결과물**: 내 GitHub에 블로그 코드 통째로 복사됨

---

## 이 강의에서 하는 일

완성된 블로그 코드(`coleitai-blog`)를 **내 GitHub 계정**으로 복사.

비유: 누가 만든 카페 설계도를 **내 이름으로 복사**해서 가져오는 단계.

---

## 따라하기

1. 브라우저 접속:
   👉 **https://github.com/colehkg-cyber/coleitai-blog**

2. 오른쪽 위 초록색 **"Use this template"** 버튼 클릭

3. **"Create a new repository"** 선택

4. 입력값:
   - **Owner**: 본인 GitHub 사용자 이름 (자동 선택됨)
   - **Repository name**: `my-blog`
   - **Description**: (비워두거나 한 줄 소개)
   - **Public** 선택 ← 필수

5. **"Create repository"** 클릭

✅ 끝.

:::tip 왜 Public이어야 하나요?
Vercel 무료 플랜은 Public이 가장 편합니다. 코드는 누가 봐도 상관 없어요. 비밀 키는 따로 분리해서 보관할 거니까요.
:::

---

## 확인하기

`https://github.com/[내사용자이름]/my-blog` 접속 → 파일이 100개 넘게 보이면 성공.

메모장에 추가:
```
[v] GitHub 저장소 URL : https://github.com/[내사용자이름]/my-blog
```
