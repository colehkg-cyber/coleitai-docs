# 1강. 도구 5개 이해하기

> **소요 시간**: 5분
> **결과물**: 무슨 도구를 왜 쓰는지 이해
> **다음 강의 준비물**: 없음. 그냥 읽고 이해만.

---

## 카페 비유로 한방에

블로그 운영은 **카페를 차리는 것**과 같습니다.

| 도구 | 카페로 치면 | 한 줄 정의 | 돈 |
|---|---|---|---|
| **Claude** | 똑똑한 알바생 | 내 대신 코드 짜주는 AI | $20/월 |
| **GitHub** | 카페 레시피 노트 | 블로그 코드 보관 창고 | 무료 |
| **Vercel** | 카페 매장 | 누구나 접속 가능한 인터넷 공간 | 무료 |
| **Turso** | 매출 장부 | 블로그 글·방문자수 저장소 | 무료 |
| **Gemini** | 글쓰기 비서 | 블로그 글 써주는 AI | 무료 |

:::tip 돈 드는 건 Claude Pro 딱 하나
나머지 4개는 평생 무료로 써도 충분합니다.
:::

---

## 각 도구가 뭔지 한 줄씩

### 1. Claude — AI 알바생
ChatGPT의 경쟁사가 만든 AI. **"Claude Code"** 라는 도구로 터미널에서 명령 하나면 AI가 내 코드를 **직접 읽고 직접 고쳐줍니다.** 100시간 배울 일을 1시간에 끝내줍니다.

### 2. GitHub — 코드 창고
**"코드용 구글 드라이브"**. 내가 코드를 바꿀 때마다 기록 → 망쳐도 과거로 되돌리기. 개인 사용 평생 무료.

### 3. Vercel — 내 블로그 매장
GitHub에 코드 올리면 **20초 안에 인터넷 주소로 바꿔줍니다.** 도메인·HTTPS 자물쇠·CDN 전부 자동. 개인 블로그 평생 무료.

### 4. Turso — 글 저장소
블로그 글·조회수를 저장하는 **온라인 엑셀** 같은 것. 9GB까지 무료 (못 채움).

### 5. Gemini — AI 글쓰기 비서
구글이 만든 AI. 키워드만 주면 블로그 글 자동 생성. 카드 등록 없이 무료. 2강 시리즈에서 본격 사용.

## 전체 흐름 한눈에

```
        Claude (AI 알바)
            ↓ 코드 작성
       ┌───────────┐
       │  내 컴퓨터  │
       └─────┬─────┘
             ↓ git push
       ┌───────────┐
       │  GitHub   │ ← 코드 저장
       └─────┬─────┘
             ↓ 자동 감지
       ┌───────────┐
       │  Vercel   │ ← 인터넷에 공개
       └─────┬─────┘
             ↓ 호출
       ┌───────────┐
       │  Turso    │ ← 글 저장
       │  Gemini   │ ← AI 글쓰기
       └───────────┘
```
