# 7강. 블로그 정보·디자인 커스텀

> **소요 시간**: 15분
> **결과물**: 내 이름·색상으로 바뀐 블로그 (GitHub에 push까지)

---

## 이 강의에서 하는 일

Claude Code에 **프롬프트만 복붙**하면 블로그 이름·저자·색상이 내 것으로 바뀝니다.

코드 직접 만질 필요 X. AI에게 한국어로 시키기만 하면 됩니다.

:::tip
`[대괄호]` 안만 본인 것으로 바꾸세요. 나머지는 그대로 복붙.
:::

---

## 📋 프롬프트 1 — 프로젝트 파악 (2분)

Claude Code(`>` 프롬프트)에 복붙:

```
이 프로젝트의 구조를 파악해줘.

1. 어떤 파일들이 있는지 트리로 보여줘
2. 블로그 이름, 저자 이름, 사이트 설명이 어느 파일에서 관리되는지 찾아줘
3. 한국어로 설명해줘
```

→ Claude가 파일 구조와 관리 파일 위치를 한국어로 보고합니다.

---

## 📋 프롬프트 2 — 블로그 기본 정보 변경 (5분)

```
블로그 기본 정보를 아래와 같이 바꿔줘.

블로그 이름: [내 블로그 이름]
블로그 설명: [한 줄 소개]
저자 이름: [내 이름 또는 닉네임]
저자 이메일: [내 이메일]

관련된 파일을 모두 찾아서 빠짐없이 바꿔줘.
바꾼 파일 목록을 한국어로 보고해줘.
```

→ Claude가 파일을 자동 수정. 변경 승인 요청이 오면 `y` 또는 Enter.

---

## 📋 프롬프트 3 — 색상 테마 변경 (5분)

```
메인 컬러를 [원하는 색상, 예: 딥그린 / 네이비 / 오렌지] 계열로 바꿔줘.
헤더, 링크, 버튼, 강조 색상 전부 통일해줘.
Lighthouse 점수(성능·접근성·SEO)에 영향 없게 유지해줘.
바꾼 파일 목록을 한국어로 보고해줘.
```

---

## 📋 프롬프트 4 — GitHub에 저장 (3분)

```
방금 바꾼 내용을 git에 커밋하고 push해줘.
커밋 메시지는 "블로그 기본 정보 및 디자인 커스텀"으로 해줘.
push 결과를 한국어로 보고해줘.
```

→ Claude가 `git add` → `git commit` → `git push` 자동 실행.
승인 요청이 오면 `y` 또는 Enter.

---

## ✅ 확인하기

`https://github.com/[내사용자이름]/my-blog` 접속 → 방금 커밋이 보이면 성공.

---

## 💡 자주 묻는 질문

**Q: 색상이 마음에 안 들어요.**
→ 프롬프트 3을 다시 보내세요. 다른 색으로 바꾸면 됩니다.

**Q: Claude가 잘못 바꿨어요. 되돌릴 수 있나요?**
→ Claude에게 이렇게:
```
방금 한 작업을 되돌려줘. 마지막 커밋 직전 상태로 되돌리고 싶어.
```

**Q: git push에서 인증 오류가 나요.**
→ Claude에게 이렇게:
```
git push 할 때 인증 오류가 났어. GitHub Personal Access Token(PAT)으로
인증하는 방법을 한국어로 단계별로 알려줘.
```
