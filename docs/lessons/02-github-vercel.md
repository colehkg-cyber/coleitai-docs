# 2강. GitHub + Vercel 가입

> **소요 시간**: 10분
> **결과물**: GitHub 계정 + Vercel 계정 (GitHub과 연동)

---

## Step 1. GitHub 계정 만들기 (5분)

1. https://github.com/signup 접속
2. 이메일 → 비밀번호 → **사용자 이름** 입력
   - **팁**: 짧고 깔끔하게. 예: `jkim-blog`
   - 이게 내 블로그 코드 주소에 들어갑니다.
3. 메일로 온 인증번호 입력 → 끝

✅ 결제카드 등록 X. 무료 그대로.

---

## Step 2. Vercel 가입 (3분)

1. https://vercel.com/signup 접속
2. **"Continue with GitHub"** 클릭 ← 반드시 이거
   - :::warning 왜 GitHub 연동인가요?
     Vercel은 GitHub과 연결돼 있어야 자동 배포가 됩니다. 이메일 가입은 비추.
     :::
3. GitHub 로그인 → "Authorize Vercel" 클릭
4. 플랜 선택 화면이 나오면 **"Hobby"** (무료) 선택
5. 끝

---

## ⏸ 메모장 체크

다음 강의 가기 전 메모장에 적어두기:

```
[v] GitHub 사용자 이름 : jkim-blog (본인 것)
[v] Vercel 가입 완료   : (GitHub 연동으로)
```
