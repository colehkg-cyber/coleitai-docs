# 10강. 자동배포 확인

> **소요 시간**: 5분
> **결과물**: 코드 수정 → 자동으로 사이트 업데이트되는 마법 확인

---

## 이 강의에서 하는 일

코드를 한 줄만 바꾸고 push해서 → **Vercel이 진짜로 자동 배포하는지** 확인.

이게 작동하면 앞으로 **새 글 쓰기 / 디자인 변경 = git push 한 번**으로 끝납니다.

---

## 📋 프롬프트 — Claude에게 시키기

Claude Code에서:

```
홈페이지 메인 타이틀 아래에 딱 한 줄만 추가해줘.

내용: "자동 배포 테스트 완료 🚀"

추가 후 git 커밋하고 push해줘.
커밋 메시지: "test: 자동배포 확인"
```

---

## 확인 순서

1. **push 완료 후 10~20초 대기**
2. https://vercel.com 접속 → 내 프로젝트 → **Deployments** 탭
3. 새 빌드가 자동으로 시작되는지 확인
   - 보통 30초~1분 안에 완료
4. 빌드 완료되면 **내 사이트 새로고침** → "자동 배포 테스트 완료 🚀" 문구가 보이면 성공! 🎉
