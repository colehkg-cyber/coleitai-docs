# SEO 기초 (1) — 구글이 어떻게 작동하는가

> 본 문서는 [Google Search Central 공식 SEO Starter Guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide?hl=ko)를 기반으로 작성되었습니다.\
> 1편: SEO 정의 + 구글 작동 원리 + E-E-A-T + 좋은 콘텐츠란?

---

## 1. SEO란 뭔가요?

### 한 줄 정의

> **검색엔진이 내 콘텐츠를 잘 이해하도록 돕고, 사람들이 내 사이트를 방문할지 결정하도록 돕는 모든 작업.**

### 구글의 공식 입장

구글이 직접 명시한 두 가지 진실:

| 진실 | 의미 |
|---|---|
| **1위를 보장하는 비결은 없다** | "이것만 하면 1위" 같은 마법은 없음 |
| **원칙을 따르면 노출 가능성이 높아진다** | 정공법을 꾸준히 → 결과가 나옴 |

### 검색 결과 반영 시간

> 변경사항이 검색결과에 반영되기까지 **몇 주~몇 달**이 걸릴 수 있습니다.

조급해하지 마세요. SEO는 **장기 게임**입니다.

| 작업 | 반영 시간 |
|---|---|
| 새 글 발행 → 색인 | 며칠 ~ 2주 |
| 색인 → 검색 결과 등장 | 1주 ~ 1개월 |
| 신생 사이트 → 안정적 순위 | 3~6개월 |
| 권위 사이트 → 1페이지 진입 | 6개월~1년 |

---

## 2. 구글은 어떻게 작동하나요? — 3단계

구글이 검색 결과를 만드는 과정은 정확히 **3단계**입니다.\
이 흐름을 이해해야 SEO 전략이 보입니다.

```
┌─────────────┐    ┌─────────────┐    ┌──────────────┐
│ ① 크롤링    │ →  │ ② 색인 생성  │ →  │ ③ 검색결과    │
│   (탐색)    │    │   (저장)    │    │   게재(순위)  │
└─────────────┘    └─────────────┘    └──────────────┘
```

### ① 크롤링 (Crawling) — 탐색

구글이 **Googlebot**이라는 로봇을 보내서 인터넷을 돌아다니며 페이지를 수집합니다.

#### 구글이 내 페이지를 발견하는 방법

1. **다른 사이트에서 내 페이지로 연결된 링크** (외부 링크/백링크)
2. **내가 직접 제출한 사이트맵** (`sitemap.xml`)
3. **Google Search Console로 직접 URL 제출** (수동)

> 💡 신생 사이트는 다른 사이트의 링크가 없으니 **사이트맵 제출이 필수**입니다.\
> 우리 템플릿은 `sitemap.xml`을 자동 생성합니다.

#### 크롤링이 막히는 이유

| 원인 | 해결 |
|---|---|
| 서버 오류 (5xx 응답) | 서버 안정성 점검 (Vercel은 거의 문제 없음) |
| `robots.txt`에서 차단 | 차단 규칙 점검 |
| 로그인 필요한 페이지 | 로그인 없이 접근 가능하게 |
| 크롤 예산 부족 | 사이트 권위 ↑ + 사이트맵 정기 업데이트 |

---

### ② 색인 생성 (Indexing) — 저장

크롤링한 페이지를 분석해서 구글 데이터베이스에 저장합니다.

#### 분석 대상

- 페이지 제목 (`<title>` 태그)
- 본문 내용
- 이미지의 alt 텍스트
- 페이지 내 링크
- 구조화 데이터 (Schema.org)
- 헤딩 구조 (H1, H2, H3)
- 발행 날짜 / 수정 날짜

> 색인 = 구글의 거대한 도서관에 내 글이 꽂히는 것

#### 색인이 안 되는 이유

| 원인 | 해결 |
|---|---|
| 콘텐츠 품질이 낮음 | 깊이 있고 고유한 글 작성 |
| `noindex` 메타 태그 | 태그 제거 |
| 자바스크립트로만 렌더링 | SSG/SSR로 HTML 렌더링 (Next.js 자동) |
| 중복 콘텐츠 | canonical 태그 설정 (자동) |
| 너무 얇은 콘텐츠 | 최소 500자 이상, 충분한 깊이 |

> 💡 우리 템플릿은 Next.js SSG 사용 → 자바스크립트 렌더링 문제 없음.

---

### ③ 검색결과 게재 (Serving) — 순위

사용자가 검색하면 저장된 페이지 중 **가장 관련성 높은 것**을 보여줍니다.

#### 순위 결정 요소

- 사용자의 **위치** (한국에서 검색 vs 미국에서 검색)
- 사용자의 **언어** (한국어 vs 영어)
- 사용자의 **기기** (모바일 vs PC)
- 검색어와 콘텐츠의 **관련성**
- 콘텐츠의 **품질** (E-E-A-T)
- 페이지 **사용자 경험** (Core Web Vitals)
- 사이트의 **권위** (백링크 등)

#### 구글의 약속

> **구글은 돈을 받고 순위를 높여주지 않는다.**\
> 순위는 알고리즘으로만 결정된다. — Google Search Central

광고(Sponsored, Ads)와 검색 결과는 완전히 별개입니다.

#### 색인은 됐는데 안 보이는 이유

| 원인 | 해결 |
|---|---|
| 검색어와 콘텐츠가 관련 없음 | 키워드 의도에 맞게 작성 |
| 콘텐츠 품질이 낮음 | E-E-A-T 강화 |
| 경쟁 글이 더 좋음 | 차별화된 정보 추가 |
| 사이트 권위가 낮음 | 시간 + 글 누적 + 백링크 |

## 3. 구글이 원하는 콘텐츠 — E-E-A-T

구글의 순위 시스템이 **공식적으로 우선순위를 두는 기준**입니다.\
2022년 12월부터 기존 E-A-T에 Experience를 추가하여 E-E-A-T가 되었습니다.

### 4가지 기준

| 약자 | 풀네임 | 한국어 | 블로그에서 예시 |
|---|---|---|---|
| **E** | **E**xperience | 경험 | 내가 직접 써본 제품 리뷰 |
| **E** | **E**xpertise | 전문성 | 해당 분야를 잘 아는 사람이 쓴 글 |
| **A** | **A**uthoritativeness | 권위 | 다른 사이트들이 내 글을 링크함 |
| **T** | **T**rustworthiness | 신뢰 | 정확한 정보, 출처 명시 |

### 가장 중요한 것: 신뢰 (Trust)

> 가장 중요한 건 **신뢰(Trust)**.\
> 나머지 3개(경험·전문성·권위)는 신뢰를 쌓기 위한 요소들. — Google Search Central

```
        T (신뢰)
        ▲
        │
   ┌────┼────┐
   │    │    │
   E    E    A
 (경험) (전문) (권위)
```

### 분야별 E-E-A-T 가중치

콘텐츠 분야에 따라 어떤 요소가 더 중요한지 다릅니다.

| 분야 | 가장 중요한 요소 | 이유 |
|---|---|---|
| **YMYL** (Your Money Your Life) — 의료·금융·법률 | 전문성 + 신뢰 | 잘못된 정보가 사용자에게 큰 피해 |
| **리뷰·평가** | 경험 | 직접 써본 사람이 쓴 글이 가치 있음 |
| **취미·DIY** | 경험 + 전문성 | 실제로 해본 사람의 노하우 |
| **뉴스·시사** | 권위 + 신뢰 | 출처가 명확한 보도 |
| **일반 정보** | 전문성 + 신뢰 | 정확하고 깊이 있는 정보 |

> 💡 본인이 가장 강점을 가진 분야를 골라야 E-E-A-T가 자연스럽게 강해집니다.

### E-E-A-T를 강화하는 실천 방법

| 항목 | 실천 방법 |
|---|---|
| **Experience** | "제가 한 달간 직접 써본 결과...", "실제 측정값 첨부..." 같은 1인칭 경험 |
| **Expertise** | 작성자 프로필 페이지 추가, 자격증·경력 명시 |
| **Authority** | 출처가 좋은 외부 사이트 인용, 외부 사이트가 내 글을 인용하게 만들기 |
| **Trust** | 출처 링크, HTTPS, 회사·저자 정보, 정확한 사실 |

## 4. 좋은 콘텐츠 vs 나쁜 콘텐츠

구글이 명시한 **공식 평가 기준**입니다.

### ✅ 구글이 보상하는 콘텐츠 (사람을 위한 콘텐츠)

| 항목 | 체크 포인트 |
|---|---|
| **고유성** | 직접 경험하거나 조사한 고유한 정보가 있다 |
| **만족도** | 독자가 읽고 나서 목적을 달성했다고 느낀다 |
| **공유 가치** | 북마크하거나 친구에게 공유하고 싶다 |
| **저자 명확성** | 저자가 누구인지 명확하다 |
| **깊이** | 표면적이 아닌, 깊이 있는 정보 |
| **정확성** | 사실관계가 정확하고, 출처가 명시됨 |
| **최신성** | 시의성 있는 정보는 최신 상태 유지 |

### ❌ 구글이 패널티를 주는 콘텐츠 (검색엔진을 위한 콘텐츠)

| 패턴 | 문제 |
|---|---|
| **검색 트래픽 유도만 목적** | 사용자 가치는 0, 키워드만 가득 |
| **여러 주제를 대량으로 얕게** | 한 사이트가 모든 주제를 얕게 다룸 |
| **다른 사이트 내용 요약** | 원본 사이트가 더 가치 있음 |
| **날짜만 바꾸고 내용은 그대로** | 신선도 조작 |
| **AI로만 뚝딱 만들고 검수 없음** | 검증되지 않은 정보 양산 |
| **얇은 콘텐츠 (Thin content)** | 200~500자, 깊이 없음 |
| **키워드 스터핑** | 키워드를 부자연스럽게 반복 |
| **클릭베이트** | 제목과 내용이 다름 |

### 구글의 AI 콘텐츠에 대한 공식 입장

> AI로 초안을 쓰되, **반드시 내 경험과 판단을 더해야 한다.**\
> AI 생성 사실을 숨기면 신뢰도가 떨어진다.

#### AI 글쓰기 가이드라인

1. ✅ AI로 초안 생성 → OK
2. ✅ 사람이 검수·수정·경험 추가 → 필수
3. ✅ AI 사용 사실을 적절히 공개 → 권장 (의료·금융은 필수)
4. ❌ AI 양산 + 검증 없음 → 패널티

## 5. 콘텐츠 자가 진단 — 3가지 질문

구글이 글 발행 전 자기 검열용으로 제시한 **공식 자가 진단**입니다.

### Q1. 누가 만들었나? (Who)

체크 사항:
- [ ] 저자 정보가 명확한가?
- [ ] 바이오(소개글)가 있는가?
- [ ] 작성자의 전문성/경험을 확인할 수 있는가?
- [ ] 연락처가 있는가?

> 💡 우리 템플릿은 작성자 정보 자동 표시 + 저자 페이지 생성.

### Q2. 어떻게 만들었나? (How)

체크 사항:
- [ ] 직접 테스트했나?
- [ ] AI를 썼다면 어떻게 활용했는지 밝혔나?
- [ ] 1차 자료를 사용했나, 다른 사이트 요약인가?
- [ ] 사실 확인 과정이 있었나?

### Q3. 왜 만들었나? (Why)

체크 사항:
- [ ] 사람을 돕기 위해서인가?
- [ ] 단순히 검색 순위를 위해서인가?
- [ ] 광고/제휴 수익만이 목적인가?

> 💡 **사람을 돕는 게 1순위, 수익은 부산물**이 되어야 합니다.\
> 이게 구글이 보상하는 사이트의 핵심 마인드셋.
