# 콘텐츠 SEO 이해하기

> 기초 공사(테크니컬 SEO) 끝. 이제 입주민(콘텐츠)을 들여야 월세가 나옵니다.\
> — 글 1개 = 월세 1건. 글이 쌓일수록 복리.

---

## 0. 콘텐츠 SEO란?

**사람들이 검색하는 키워드에 맞는 글을 써서, 구글 검색 상위에 노출시키는 것입니다.**

쉽게 말하면:

| 비유 | 테크니컬 SEO | 콘텐츠 SEO |
|------|------------|-----------|
| 건물 | 기초 공사 완료 ✅ | 이제 세입자(글)를 들이자 |
| 역할 | 구글 봇이 좋아하는 **구조** | 사람이 좋아하는 **내용** |
| 빈도 | 한 번 세팅하면 끝 | 꾸준히 글을 쓴다 |
| 누가? | 템플릿이 해결 | **여러분이 하는 것** |

> 💡 **건물(사이트)은 완성했습니다.** 이제 세입자(글)가 필요합니다.\
> 세입자가 없는 건물에서는 월세가 안 나오잖아요?\
> 글이 없는 사이트에서는 트래픽(방문자)이 안 옵니다.

## 1. 황금 키워드 공식

이것이 구글 건물주 프로젝트의 **가장 중요한 전략**입니다.

```
┌──────────┐     ┌──────────┐     ┌──────────────┐
│ 검색량    │  ×  │ 경쟁도    │  =  │  황금 키워드   │
│   HIGH   │     │   LOW    │     │  🏆 대박!     │
└──────────┘     └──────────┘     └──────────────┘
```

무슨 뜻이냐면:

- **검색량이 높다** = 사람들이 이 키워드로 많이 검색한다
- **경쟁도가 낮다** = 이 키워드에 대해 좋은 글이 별로 없다
- **두 조건이 동시에 충족** = 여기에 글을 쓰면 1페이지 장악 가능!

이런 키워드를 **"빈 땅"**이라고 부릅니다.\
사람들은 찾아오는데, 건물(좋은 글)이 없는 땅.\
여기에 400점짜리 사이트로 좋은 글을 올리면? **독점!**

### 실전 예시

```
키워드: "맥북 에어 M3 발열 해결법"
─────────────────────────────────
검색량:    월 2,400회 → 사람들이 꽤 많이 검색함 ✅
경쟁 상태:  상위 글들이 3년 전 글, 내용 부실 ✅
기존 글:   오래되고 정보가 틀림 ✅
─────────────────────────────────
→ 황금 키워드 확정! 🏆
→ 최신 정보로 글을 쓰면 1페이지 진입 가능
```

### 키워드 분류 — 머리(Head) vs 꼬리(Long-tail)

| 분류 | 예시 | 검색량 | 경쟁도 | 추천 |
|---|---|---|---|---|
| **Head 키워드** | "맥북" | 매우 높음 (월 100만+) | 매우 높음 (대기업 도배) | ❌ |
| **Body 키워드** | "맥북 에어 발열" | 중간 (월 1만~) | 중간 | △ |
| **Long-tail 키워드** | "맥북 에어 M3 발열 30분 후 70도" | 낮음 (월 200~) | 낮음 | ✅ |

### 신생 사이트는 무조건 Long-tail부터

> **Long-tail 키워드 = 신생 사이트의 친구**\
> 검색량은 작지만, 1위 진입이 쉬움.\
> Long-tail 100개가 모이면 → Head 키워드 1개보다 많은 트래픽.

예시:
- "맥북 에어 발열" (월 1만 검색, 100위) → 트래픽 0
- "맥북 에어 M3 발열" + "맥북 에어 M3 발열 게임" + "맥북 에어 M3 발열 70도" 등 50개 (각 월 200 검색, 1~5위) → 합계 월 8천 트래픽

## 2. 검색 의도 — 사람들은 왜 검색하는가?

같은 "맥북"이라는 단어로 검색해도, 사람마다 원하는 게 다릅니다.\
이걸 **검색 의도(Search Intent)**라고 합니다.

| 유형 | 사람의 마음 | 검색 예시 | 우리가 쓸 글 스타일 |
|------|-----------|----------|-----------------|
| **정보형 (Informational)** | "이게 뭔지 알고 싶다" | "맥북 에어 발열 원인" | 설명 가이드 |
| **비교형 (Investigational)** | "뭐가 더 나은지 알고 싶다" | "맥북 에어 vs 프로" | 상세 비교표 |
| **해결형 (Transactional)** | "문제를 풀고 싶다" | "맥북 발열 해결법" | 해결 방법 글 |
| **구매형 (Commercial)** | "사고 싶다" | "맥북 에어 최저가" | 리뷰 + 구매 링크 |
| **네비게이션형 (Navigational)** | "특정 사이트 가고 싶다" | "애플 홈페이지" | 해당 없음 |

### 검색 의도 파악법 — SERP 분석

가장 정확한 방법: **구글에서 직접 검색해보기**

1. 타겟 키워드를 구글에 검색
2. 상위 10개 결과를 보고 **공통점** 찾기
   - 다 가이드 글이다 → 정보형
   - 다 비교표가 있다 → 비교형
   - 다 쇼핑몰이다 → 구매형
3. **그 의도에 맞춰** 글을 작성

> 💡 의도와 맞지 않으면 절대 상위 노출 안 됩니다.\
> 예: "맥북 최저가"라는 구매형 키워드에 정보 글을 쓰면 → 절대 안 뜸.

### 우리가 노려야 할 유형은?

**정보형 + 해결형**이 가장 좋습니다.

왜?
- 비교형, 구매형은 새 제품이 나오면 글이 쓸모없어져요
- 정보형/해결형은 **오래 갑니다** (글 1개 = 월세 1건이 제대로 작동!)

> 💡 물론 비교형, 구매형도 쓰면 좋습니다.\
> 특히 제휴 마케팅(제품 추천해서 수수료 받기)에는 이런 글이 효과적이에요.\
> 하지만 **메인은 정보형/해결형**으로 가는 게 안정적입니다.

## 3. E-E-A-T — 구글의 공식 평가 기준

2022년부터 구글이 공식적으로 강조하는 콘텐츠 품질 기준:

| 글자 | 풀네임 | 한국어 | 무엇? |
|---|---|---|---|
| **E** | Experience | 경험 | 직접 경험한 내용인가? |
| **E** | Expertise | 전문성 | 작성자가 전문 지식이 있는가? |
| **A** | Authoritativeness | 권위 | 해당 분야의 권위가 있는가? |
| **T** | Trustworthiness | 신뢰 | 정보가 정확하고 출처가 있는가? |

### 왜 중요한가?

구글이 2022년 12월 **Helpful Content Update**를 발표하면서 강조:

> "사람을 위한, 사람에 의해 만들어진 콘텐츠가 검색에서 성공합니다.\
> AI가 양산한 저품질 콘텐츠는 페널티를 받습니다." — Google Search Central

### E-E-A-T 강화 방법

| 항목 | 실천 방법 |
|---|---|
| **Experience** | "제가 직접 써봤는데...", "한 달간 측정한 결과..." 같은 1인칭 경험 추가 |
| **Expertise** | 작성자 프로필 추가 (저자 페이지) — `<author>` 태그 |
| **Authority** | 외부 사이트가 내 글을 인용하게 만들기 (백링크) |
| **Trust** | 출처 명시 (논문, 공식 발표 링크), HTTPS 사용, 회사/저자 정보 명확화 |

### AI 글쓰기와 E-E-A-T

> **AI가 쓴 글은 페널티 아닙니다.**\
> 단, **AI 양산 + 검증 없음 + 경험 0** = 페널티.

올바른 방법:
1. AI로 초안 생성
2. **본인이 직접 경험한 내용 추가** (Experience)
3. 사실 검증 (Trust)
4. 작성자 정보 명시 (Expertise, Authority)

## 4. Helpful Content Update — AI 시대의 새 규칙

2022년 12월 ~ 2023년 9월 사이에 구글이 알고리즘을 대폭 업데이트했습니다.

### 변화된 평가 기준

| 기존 | 새 기준 |
|---|---|
| 키워드 밀도 | 사용자가 정말 도움받았는지 |
| 글의 길이 | 실제 가치 (양보다 질) |
| 백링크 수 | 자연스럽고 권위 있는 백링크만 |
| 어떻게 만들어졌는지 (AI? 사람?) | 사용자에게 유용한가? |

### 페널티 대상

구글이 공식적으로 페널티를 주는 콘텐츠:

1. **AI 양산 콘텐츠** (검증 없이 대량 생성)
2. **얇은 콘텐츠** (Thin content) — 200~500자, 깊이 없는 글
3. **클릭베이트** — 제목과 내용이 다름
4. **검색엔진만을 위한 글** — 사람이 읽기 어려운 글
5. **부정확한 정보** — 사실관계 틀린 글

### 구글의 공식 입장 (2023)

> "우리는 콘텐츠가 **어떻게** 만들어졌는지가 아니라,\
> 사용자에게 **유용한지**를 평가합니다." — Google, 2023

**결론:** AI로 쓰되, 사람이 검수하고 **개인 경험을 추가하면 OK!**

## 5. 글의 구조 — 1페이지 가는 템플릿

상위 노출되는 글들의 공통 구조:

```
┌─────────────────────────────────────┐
│  ① 제목 (H1) — 키워드 포함          │
│  ② 메타 디스크립션 (150자)          │
│  ③ 도입부 (3~5문장)                 │
│     - 문제 제시                     │
│     - 글에서 얻을 수 있는 것        │
│  ④ 목차 (Table of Contents)         │
│  ⑤ 본문 (H2 × 3~7개)               │
│     - 각 H2당 H3 × 1~3개            │
│     - 이미지 1~2개                  │
│     - 표/리스트 적극 활용           │
│  ⑥ FAQ 섹션                         │
│  ⑦ 결론 + 다음 글 링크 (내부 링크)  │
└─────────────────────────────────────┘
```

### 헤딩 구조 예시

```
H1: 맥북 에어 M3 발열 해결법 — 30분 만에 끝내기
  H2: 1. 맥북 에어 M3 발열의 4가지 원인
    H3: 1-1. 고사양 작업 (영상 편집, 게임)
    H3: 1-2. 환경 요인 (실내 온도, 통풍)
    H3: 1-3. 백그라운드 프로세스
    H3: 1-4. 하드웨어 설정 문제
  H2: 2. 즉시 적용 가능한 해결법 3가지
    H3: 2-1. 활성 상태 보기로 프로세스 확인
    H3: 2-2. 노트북 받침대 사용
    H3: 2-3. 전원 관리 설정 변경
  H2: 3. 발열 측정 방법
  H2: 자주 묻는 질문 (FAQ)
```

### 글 길이의 미신 vs 진실

| 미신 | 진실 |
|---|---|
| "2000자 이상 써야 SEO에 좋다" | 키워드 의도에 따라 다름 |
| "길수록 좋다" | 의도에 맞는 적정 길이가 중요 |
| "AI는 길게 못 쓴다" | Claude/Gemini는 충분히 깊이 있게 작성 |

**실제 평균 길이 (상위 10위 글 기준):**

| 의도 | 평균 글자수 |
|---|---|
| 정보형 (가이드) | 1,500~3,000자 |
| 해결형 (How-to) | 1,000~2,000자 |
| 비교형 | 2,000~4,000자 |
| 구매형 (리뷰) | 1,500~3,000자 |
| 짧은 정의 ("X란?") | 500~1,000자 |

## 6. SERP Features — 검색 결과의 특수 영역

요즘 구글 검색 결과는 단순한 10개 목록이 아닙니다.\
다양한 **특수 영역**이 있어요.

| 영역 | 모습 | 우리 전략 |
|---|---|---|
| **Featured Snippet** | 검색 결과 맨 위 박스 (정답 발췌) | 짧고 명확한 정의/단계로 작성 |
| **People Also Ask** | "사람들이 함께 묻는 질문" | FAQ 섹션으로 적중 |
| **Knowledge Panel** | 오른쪽 큰 카드 (위키 같은 것) | 구조화 데이터로 강화 |
| **Image Pack** | 이미지 가로 배치 | 이미지 alt 텍스트 + 파일명 |
| **Video Carousel** | 동영상 영역 | YouTube 연동 시 유리 |
| **Local Pack** | 지도 + 가게 정보 | 로컬 비즈니스용 |

### Featured Snippet 노리는 글쓰기 팁

```
질문 형식의 H2:
─────────────
H2: 맥북 에어 M3 발열은 정상인가요?

바로 다음에 짧은 답:
─────────────
맥북 에어 M3의 70~85도는 정상 범위입니다.
다만 85도 이상이 30분 이상 지속되면 발열 관리가 필요합니다.

그다음 상세 설명:
─────────────
(이어지는 디테일...)
```

이런 구조로 쓰면 Featured Snippet에 채택될 확률이 ↑

## 7. AI 글쓰기의 핵심

### Claude/Gemini에게 글을 시키는 흐름

```
1. 황금 키워드를 찾는다
       ↓
2. SERP 분석 — 상위 10개 글 어떻게 썼는지 확인
       ↓
3. AI에게 "이 키워드로 블로그 글 써줘 + 가이드 추가" 한다
       ↓
4. AI가 초안을 써줌
       ↓
5. 내가 읽어보고, 개인 경험을 추가한다 ← 이게 핵심!
       ↓
6. 사실 검증 + 이미지 추가
       ↓
7. 블로그에 올린다 → 자동 배포!
```

### AI 프롬프트 예시

```
다음 조건으로 블로그 글을 작성해줘:

키워드: "맥북 에어 M3 발열 해결법"
검색 의도: 해결형 (How-to)
대상: 맥북 에어 M3을 막 산 사용자
길이: 1,500~2,000자
구조:
  - H1: 키워드 포함된 매력적 제목
  - 도입부 3문장 (문제 제시 + 글에서 얻을 것)
  - H2 × 4개: 원인, 해결법, 측정 방법, FAQ
  - 각 H2 아래 H3 × 2~3개
  - 표 1개 (해결법 정리)
  - FAQ 5개

요구사항:
  - 1인칭 경험 추가 ("제가 실제로 측정해보니...")
  - 외부 출처 링크 1~2개 포함
  - alt 텍스트 가이드: 각 이미지 위치에 "[이미지: ...]" 표기
```

이렇게 디테일하게 시키면 AI가 1페이지급 글을 만들어줍니다.

## 8. 내부 링크 — 사이트 권위 키우는 비밀

글을 쓸 때마다 **다른 글로 연결**하세요.

### 효과 3가지

1. **사용자가 사이트에 더 오래 머뭄**
   - 1글 읽고 → 2글 읽고 → 3글 읽기
   - 체류 시간 ↑ → 구글이 "유용한 사이트구나" 평가
2. **구글 봇이 사이트를 깊이 탐색**
   - 새 글이 빨리 발견됨
3. **권위(Authority) 전달**
   - 1위 글에서 신규 글로 링크 → 신규 글이 빠르게 상승

### 좋은 내부 링크 vs 나쁜 내부 링크

```
❌ 나쁜 예: "여기 클릭하세요"
✅ 좋은 예: "맥북 에어 발열 원인은 별도 글에서 다뤘습니다"
```

링크 텍스트에 **키워드를 자연스럽게** 포함시키세요.

```
    ↓         ↓         ↓
[Cluster]  [Cluster]  [Cluster]
"발열"     "키보드"    "배터리"
    ↓         ↓         ↓
    ...       ...       ...
```

### 어떻게 작동하나?

1. **Pillar Page** (기둥 글): 큰 주제의 종합 가이드 (3,000~5,000자)
2. **Cluster Pages** (가지 글): 하위 주제의 세부 글들 (각 1,500자)
3. 모두 서로 연결 (내부 링크)

### 효과

- 구글이 "이 사이트는 맥북 에어 전문가구나" 인식
- 새 글을 올려도 빠르게 1페이지 진입 (Authority 효과)

> 💡 본 강의에서는 **글 10~20개를 한 주제로 묶어** 토픽 클러스터 만드는 걸 권장합니다.

---

## 10. 글의 수명 — 왜 구글이 네이버보다 나은가

이게 가장 중요합니다. 잘 보세요!

### 네이버 블로그 글
```
트래픽 ↑
      │  ╱╲
      │ ╱  ╲──── 2~4주 후 사라짐...
      │╱    ╲
      └──────────── 시간 →
```
글 올리면 2~4주 반짝 → 그다음 트래픽 0 → **또 써야 함**\
글 안 쓰면 수입 0. 노동집약적이에요.

### 구글 SEO 글
```
트래픽 ↑
      │            ╱────── 6개월~수년 유지!
      │          ╱
      │        ╱
      │      ╱
      │    ╱
      └──────────── 시간 →
```
처음 1~2달은 천천히 올라감 → 한 번 올라가면 **계속 유지!**\
6개월, 1년, 3년... 꾸준히 트래픽이 들어옴

> 🏠 **글 1개 = 월세 1건입니다.**\
> 글이 쌓일수록 월세가 늘어납니다.\
> 이게 "구글 건물주"의 본질이에요.\
> 글을 쌓아가면 **복리**처럼 트래픽이 불어납니다.

---

## 11. 글 업데이트 (Content Refresh) — 잊지 마세요

쓴 글을 그대로 두지 마세요. **주기적으로 업데이트**하면 트래픽이 다시 오릅니다.

### 언제 업데이트?

- 정보가 오래됐을 때 (날짜·버전 변경)
- 새로운 사실이 추가됐을 때
- 상위에서 밀려나기 시작할 때
- 6개월~1년에 한 번 정기 검토

### 업데이트 효과

구글은 **Freshness Signal**을 봅니다:
- 최근 업데이트된 글 → "최신 정보구나"
- 1년+ 안 만진 글 → "오래됐네"

> 💡 발행 날짜뿐 아니라 **수정 날짜**도 함께 표시되면 좋음.\
> 우리 템플릿은 자동 처리합니다.

## 12. 글이 쌓이면 어떻게 되나요?

| 글 수 | 예상 월 트래픽 | 비유 |
|-------|-------------|------|
| 10개 | 500~1,000명 | 원룸 건물 |
| 30개 | 3,000~5,000명 | 소형 빌딩 |
| 50개 | 10,000~20,000명 | 중형 빌딩 |
| 100개+ | 50,000명+ | 대형 빌딩 |
| 200개+ | 200,000명+ | 본 강의자 수준 |

글 1개 1개가 다 세입자입니다.\
**세입자가 많을수록 월세가 늘어납니다.** 꾸준히 쓰세요!
