# SEO 심화 (2) — 코너스톤 페이지 & 백링크·인링크

> 1편이 "글 한 편 잘 쓰기" 였다면, 2편은 **블로그 전체를 한 덩어리로 연결하는 전략** 입니다.\
> — 코너스톤 페이지 / 인링크 / 백링크 / 콘텐츠 보완 / 구글 패널티 회피

---

## 1. 코너스톤 페이지 (Cornerstone)

### 코너스톤 페이지란?
> 블로그에서 **가장 중요한 주제**에 대해 **가장 길고 포괄적으로 쓴 글**. 다른 글들을 연결하는 **허브** 역할.

비유: 백화점의 **메인 안내데스크**.
- 손님이 들어오면 우선 안내데스크에서 전체 구조를 봅니다
- 거기서 각 매장(개별 글)으로 흩어집니다

### 일반 글 vs 코너스톤

| 항목 | 일반 글 | 코너스톤 페이지 |
|---|---|---|
| 글자 수 | 2,500~4,000자 | **5,000~8,000자** |
| H2 섹션 수 | 4~6개 | **8~12개** |
| 내부 링크 | 5개 내외 | **10개 이상** |
| 주제 범위 | 좁고 깊게 | 넓고 종합적 |
| 빈도 | 매일/매주 | **3개월에 1편** |

### 코너스톤 페이지의 효과
- 메인 키워드 검색량이 큰 주제 1페이지 진입
- 다른 글들이 코너스톤을 가리키며 권위 점수 ↑
- 사이트 전체 SEO 점수 동시 상승

### 예시 구조
```
블로그 주제: "재택근무"
  코너스톤: "재택근무 완벽 가이드 (8,000자)"
      ├── 일반 글: "재택근무 책상 추천"
      ├── 일반 글: "재택근무 의자 BEST 5"
      ├── 일반 글: "재택근무 시 집중력 높이는 법"
      ├── 일반 글: "재택근무 세금 신고"
      └── (코너스톤이 위 글 모두에 링크)
```

> 💡 블로그 시작 직후가 아니라, **일반 글이 20~30편 쌓인 뒤** 그것들을 종합해서 만드는 게 효과적.

## 2. 인링크 vs 백링크 — 같은 듯 다른 둘

### 한 줄 정의
- **인링크 (Internal Link)** = 내 블로그 안에서 다른 글로 가는 링크
- **백링크 (Backlink, 외부링크)** = 다른 사이트에서 내 블로그로 들어오는 링크

### 비교표

| 항목 | 인링크 (Internal) | 백링크 (External) |
|---|---|---|
| 출발지 | 내 블로그 안 다른 글 | **외부 사이트 / SNS** |
| 도착지 | 내 블로그 안 글 | 내 블로그 안 글 |
| 내가 통제 가능? | ✅ 완전 가능 | ❌ 외부의 선택 |
| SEO 효과 | 사이트 내부 권위 분산 | **외부 권위 가져오기** |
| 만들기 난이도 | 쉬움 (글 쓸 때 추가) | 어려움 (외부에 의존) |

---

## 3. 인링크 전략 — 내가 100% 통제 가능한 SEO 무기

### 글마다 5개 이상 삽입 권장

새 글을 발행할 때마다 다음을 확인:
1. 이 글과 **연관된 기존 글 5개**를 찾는다
2. 새 글 본문에 그 5개로 가는 링크 삽입
3. **기존 5개 글 본문에도** 새 글로 가는 링크 추가 (양방향)
4. 앵커 텍스트는 매번 다르게

### 앵커 텍스트 다양화 예시 (스터핑 회피)

| 잘못된 방식 ❌ | 올바른 방식 ✅ |
|---|---|
| 맥북 추천 → /macbook | 가성비 노트북 → /macbook |
| 맥북 추천 → /macbook | 애플 노트북 비교 → /macbook |
| 맥북 추천 → /macbook | M3 모델 상세 → /macbook |

→ 같은 URL을 가리켜도 앵커는 매번 다르게.

### 인링크 자동화
`/admin` → 글 관리 → 발행된 글 검수 시 "다른 글 더 보기" 섹션에 자동 노출되도록 설정 가능. (블로그 템플릿 기본 제공)

## 4. 백링크 전략 — 외부에서 끌어오는 권위

### 왜 중요한가?
구글은 백링크를 **"이 사이트 좋아요" 추천표** 로 봅니다. 백링크 수·질이 곧 사이트 권위 점수.

### 무료 백링크 등록 사이트 5곳

1. **smallseotools.com/backlink-maker**
2. **seowagon.com/backlink-maker**
3. **real-backlinks.com**
4. **backlinkr.net**
5. **searchenginereports.net/backlink-maker**

### 등록 절차 (공통)
1. 사이트 접속 → "Backlink Maker" 입력창에 내 글 URL 붙여넣기
   - 예: `https://my-blog.vercel.app/posts/macbook-review`
2. "Create Backlinks" 클릭
3. 30초~2분 대기 → 100~500개 외부 링크 자동 생성됨

### 더 강력한 백링크 (수동)
- 네이버 카페 / 블로그 댓글에 자연스럽게 링크
- 디시인사이드 / 클리앙 글 답변에 출처로 인용
- 페이스북 그룹 / 카카오톡 오픈채팅에 공유
- 게스트 블로깅 (다른 블로그에 글 쓰고 출처 표시)

### 측정 방법
- **구글 서치 콘솔 → 링크 메뉴**
- 외부 링크 / 내부 링크 수 추적
- 인링크 5개 이상부터 SEO 효과 가시화

> ⚠️ **블랙햇 절대 금지**: 돈 주고 백링크 1만 개 사기, 봇으로 댓글 스팸 등. 구글이 잡으면 사이트 영구 페널티.

## 5. 콘텐츠 보완 — 기존 글 업그레이드

### 왜 보완이 새 글보다 중요할 때가 있는가?

구글 서치 콘솔 → 평균 게재순위 **1.1~10등** 사이 글이 가장 가치 있음. 이 글들을 보완하면 **순위 1~3등 진입 → 트래픽 3~5배**.

### 보완 체크리스트
1. **시기 표현 업데이트**
   - "2023년 기준" → "2026년 기준"
   - 오래된 가격·스펙·통계 최신화
2. **누락 스니펫 요소 추가**
   - 표 없으면 → 비교표 추가
   - 단계 없으면 → 넘버링 추가
   - FAQ 없으면 → Q&A 3개 추가
3. **본문 길이 30~50% 보강** (단, 의미 있는 추가만)
4. **인링크 최소 3개 추가**
5. **이미지 alt 텍스트 점검**
6. **메타 디스크립션 재작성**

### ⚠️ 보완 시 절대 하지 말 것
- **기존 URL 변경 금지** (SEO 기록·백링크 다 날아감)
- 기존 H1 키워드는 그대로 유지 (소소한 수정만)

## 6. 구글 패널티 회피 — 절대 하지 말 것

| 금지 행위 | 결과 |
|---|---|
| 같은 키워드 본문에 10회 이상 반복 | 키워드 스터핑 패널티 |
| 동일 앵커 텍스트 링크 남발 | 스팸 의심 |
| AI 글 그대로 발행 (검수 0) | E-E-A-T 점수 ↓ |
| 메타 디스크립션 모든 글에 동일 | 스니펫 미생성 |
| H1 여러 개 사용 | 구조 점수 ↓ |
| 제목과 내용 불일치 (낚시) | 이탈률 ↑ → 순위 ↓ |
| "100%", "무조건", "절대 최고" 남발 | 신뢰도 ↓ |
| 돈 주고 백링크 1만 개 구매 | **영구 패널티** |
| 봇으로 자동 댓글·링크 생성 | 사이트 색인 제외 |

### 핵심 원칙
> **사람을 위한 글을 써라. 검색엔진은 사람을 따라온다.** — 구글 공식 가이드

## 7. 운영 흐름 정리

```
1주차: 일반 글 7편 발행
        ↓
2~4주: 일반 글 계속 발행 + 인링크 부지런히 연결
        ↓
2개월: 발행 글 20편 도달
        ↓
3개월: 누적 글들을 종합한 코너스톤 페이지 1편 발행
        ↓
   기존 20편이 코너스톤 가리키도록 인링크 추가
        ↓
   백링크 등록 5사이트 진행
        ↓
   서치 콘솔에서 순위 1.1~10등 글 골라 보완
        ↓
   → 사이트 전체 권위 점수 상승, 1페이지 진입 가속화
```

## 🤖 코너스톤 자동화 — `/admin/cornerstone`

위 개념을 손으로 하면 한 편 만드는 데 4~6시간. 템플릿에는 **5편 묶어서 자동 생성**해주는 기능이 내장돼 있습니다.

### 흐름 (5분)

```
1. /admin/cornerstone → [+ 새 코너스톤 생성]
2. 메인 키워드 입력 (예: "재택근무")
3. 발행글 목록에서 묶을 글 3~5개 체크
   - 같은 카테고리/태그 인기글이 효과적
4. [AI로 코너스톤 초안 생성] → 30~60초 대기
   → DRAFT 상태로 저장 + 편집 화면 자동 이동
5. 본문 검토 후 [발행] 클릭
   → source 글 5편 본문 끝에 자동으로 "📚 종합 가이드" 박스 삽입
```

### 자동 처리되는 것

| 항목 | 자동 처리 내용 |
|---|---|
| 글자 수 | Gemini가 5,000~8,000자 종합 작성 |
| H2 섹션 | 8~12개 자동 분배 (인트로 + 본문 + 결론) |
| 인링크 (코너스톤 → source) | 각 H2 끝에 "👉 자세히: [원본 글](/posts/slug)" 자동 |
| 인링크 (source → 코너스톤) | 5편 본문 끝에 박스 자동 삽입, DB 영구 저장 |
| OG 이미지 | Unsplash 자동 검색 → 1200×630 fallback |
| URL slug | 영문 케밥 케이스 자동 |
| Meta description | 150~160자 자동, 메인 키워드 포함 |

### 전제 조건

- 발행글이 **20편 이상** 쌓인 후 권장 (3개월 운영 후)
- 같은 메인 키워드를 다루는 글이 **5편 이상** 있어야 효과
- 너무 일찍 만들면 코너스톤끼리 카니발리제이션 발생

### 박스 형식

source 글 본문 끝에 자동 삽입되는 박스:

```
---

## 📚 이 주제의 종합 가이드

[**재택근무 완벽 가이드**](/posts/remote-work-complete-guide) — 더 자세한 내용을 한 편에 모았습니다.
```

> 💡 박스는 HTML 주석 delimiter로 감싸져 저장됩니다. 코너스톤 재발행 시 자동 갱신, 코너스톤 삭제 시 다음 발행에서 자동 제거.
