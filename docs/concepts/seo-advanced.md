# SEO 심화 (1) — 피처드 스니펫 & 키워드 전략

> 콘텐츠 SEO 기본기를 마쳤다면, 이제 **구글 1페이지 0순위(피처드 스니펫)** 를 노립니다.\
> — 1편: 스니펫 7요소, 키워드 스터핑 방지, LSI 키워드, 제목 공식, Heading 계층

---

## 0. 왜 심화가 필요한가?

콘텐츠 SEO 기본기 = "글을 잘 쓰자". 충분히 좋은 출발이지만 **상위 1~5등은 진입 가능, 0순위(피처드 스니펫)는 불가** 입니다.

피처드 스니펫은 검색 결과 맨 위에 **박스 형태로 답을 미리 보여주는 자리** 예요. 0순위라고 부릅니다.

```
구글 검색 결과
┌──────────────────────────────────┐
│ 광고 (Ads)                        │
├──────────────────────────────────┤
│ 🌟 피처드 스니펫 (0순위)            │ ← 여기!
│   질문에 대한 단답 박스             │
├──────────────────────────────────┤
│ 1등 — 일반 검색 결과                │
│ 2등 — 일반 검색 결과                │
│ ...                              │
└──────────────────────────────────┘
```

이 자리에 노출되면 **클릭률이 4~8배 폭증**. 이 글에서는 그 자리를 차지하는 방법을 다룹니다.

---

## 1. 피처드 스니펫의 7가지 요소

구글이 0순위로 뽑는 글에는 공통점이 있습니다. 아래 7개 중 **최소 4개**를 글마다 의식적으로 포함하세요.

| # | 요소 | 의미 | 예시 |
|---|---|---|---|
| 1 | 넘버링 | 순서 있는 단계 정리 | "1. 가입 2. 인증 3. 결제" |
| 2 | 불릿 리스트 | 순서 없는 항목 나열 | "• 빠름 • 저렴 • 안전" |
| 3 | 비교/정리 테이블 | 가로 3열 이상 | 제품 A vs B vs C |
| 4 | 질문 + 답변 형식 | FAQ + 본문 안에도 1~2개 | "Q. ... A. ..." |
| 5 | 논리적 구획(section) | H2/H3 구조로 명확히 | "## 단점 / ## 추천 대상" |
| 6 | 인용구 | 핵심 문장 강조 | "> 결국 핵심은 X다." |
| 7 | 양질의 정보 | 수치·날짜·출처 | "2026년 기준 65%" |

> 💡 자동 발행되는 글에도 이 요소가 들어가도록 시스템 지침에 명시합니다. (`/admin` → 전문 지식)

---

## 2. 피처드 스니펫 노리기 — 구조 공식

피처드 스니펫 박스에 뽑히는 글의 90%는 **이 구조** 입니다.

```
## ~하는 방법 (질문형 H2)
  ↓
40~60자 단답형 정의 문장 1개
  ↓
넘버링 또는 표로 상세 설명
```

### 좋은 예
```markdown
## 다크모드 설정하는 방법

다크모드는 헤더 우측 달 아이콘을 클릭해 켜고, 같은 위치의 해 아이콘으로 끕니다.

1. 헤더 우측 아이콘 확인
2. 달 아이콘 클릭 → 다크 적용
3. 해 아이콘 클릭 → 라이트 복귀
```

### 나쁜 예 (스니펫 진입 어려움)
```markdown
## 사용 방법

블로그를 사용하는 데에는 여러 가지 방법이 있습니다. 우선...
(길게 풀어쓰기만 함, 단답 박스 만들 자리 없음)
```

> 글마다 H2 중 **최소 1개**는 질문형으로. "~란 무엇인가", "~하는 방법", "~ 차이".

## 3. 키워드 스터핑 절대 금지

### 키워드 스터핑이란?
> 같은 키워드를 부자연스럽게 반복해서 검색 엔진을 속이려는 행위.

구글은 2011년 이후 이걸 **패널티 1순위**로 잡습니다. 한 번 걸리면 순위가 깊은 곳으로 떨어집니다.

| 항목 | 잘못된 예 | 안전한 횟수 |
|---|---|---|
| 본문 안 키워드 등장 | 같은 단어 10회↑ | **3~5회만** |
| 같은 앵커 텍스트 링크 | "맥북" 링크 5개 | 매번 다른 표현 |
| 제목·H2·메타 모두 동일 키워드 | 똑같이 박음 | 위치별로 변형 |

### 키워드 배치 위치 (3~5회 분산)
- Title 태그 (H1) — 1회
- 메타 디스크립션 — 1회
- 첫 문단 100자 이내 — 1회
- H2 중 1개 — 1회
- 결론 마지막 문단 — 1회

→ **5회 정도가 자연스러움의 한계.**

## 4. LSI 키워드 — 유의어로 분산

### LSI 키워드란?
> **L**atent **S**emantic **I**ndexing keyword. 메인 키워드와 의미적으로 연관된 유의어/관련어.

예: 메인 키워드 = "맥북"
```
LSI 키워드 후보:
- 노트북
- 애플 노트북
- M3 모델
- 맥북에어
- 애플 컴퓨터
- 맥OS 노트북
```

### 활용 방법
글에서 같은 키워드를 반복할 자리가 나오면 → 위 LSI 키워드 중 하나로 바꾸기.

| Before (스터핑) | After (LSI 분산) |
|---|---|
| 맥북 추천. 맥북 가격. 맥북 성능. 맥북 단점. 맥북 종류... | 맥북 추천. **노트북** 가격. **애플 노트북** 성능. **M3 모델** 단점. **맥북에어** 종류... |

→ 구글 봇은 동일 주제로 인식 + 스터핑 패널티 회피.

## 5. 제목 공식 (클릭률 2배 차이)

블로그 제목 하나로 트래픽이 2배 차이 납니다. 검증된 공식:

```
혜택 + 숫자 + 형용사 + 타깃 키워드
```

### 적용 예시

| 약한 제목 ❌ | 강한 제목 ✅ |
|---|---|
| 맥북 사용법 | **클릭을 부르는 7가지 쉬운 맥북 활용법** |
| 다이어트 식단 | **3주 만에 5kg 빠진 진짜 다이어트 식단 5가지** |
| 카페 추천 | **현지인만 아는 강남 숨은 카페 BEST 7** |

### 제목 작성 규칙
- 60자 이내 (구글 검색 결과에서 잘리지 않음)
- 키워드는 **맨 앞쪽**에 배치
- 동사로 끝나지 않게 ("~하기" 보다는 "~하는 법")
- 숫자 포함 (5가지, 7개, TOP 10 등)

## 6. Heading 계층 — H1 → H3 건너뛰기 금지

### 올바른 계층
```
H1 (글 제목, 정확히 1개)
├── H2 (메인 섹션)
│   ├── H3 (서브 섹션)
│   │   └── H4 (상세 항목)
│   └── H3
└── H2
```

### 자주 하는 실수

| 실수 | 결과 |
|---|---|
| H1을 여러 개 사용 | 구조 점수 ↓ |
| H1 → H3로 점프 (H2 빼먹기) | 봇이 계층 파악 실패 |
| H4 다음에 갑자기 H2 | 논리 구조 깨짐 |
| `<b>`, `<strong>` 으로 큰 제목 흉내 | 검색 노출 ↓ (시각만 비슷) |

> 💡 Claude Code에게 "글 발행 전에 Heading 순서 점검해줘" 한 줄만 추가해도 자동 검수됩니다.

---

## 7. 메타 디스크립션 — 글마다 고유하게

검색 결과에서 제목 아래 회색 글씨 = 메타 디스크립션. 클릭률에 직접 영향.

| 항목 | 규칙 |
|---|---|
| 길이 | 155자 이내 (잘림 방지) |
| 키워드 | 1회만 자연스럽게 |
| 중복 | 절대 금지 (모든 글마다 고유) |
| 내용 | 페이지 요약 + 클릭 유도 |

### 예시
```
❌ 매번 같음: "최고의 블로그입니다. 방문하세요."
✅ 글마다 고유: "M3 맥북에어를 3개월 써본 솔직한 후기. 배터리·성능·단점까지 사용 데이터로 정리했습니다."
```

---

## ✅ 1편 체크리스트

- [ ] 피처드 스니펫의 7요소를 외운다
- [ ] 글마다 H2 중 1개는 질문형으로 만든다
- [ ] 메인 키워드는 3~5회 이내, 나머지는 LSI로 분산한다
- [ ] 제목은 "혜택+숫자+형용사+키워드" 공식을 적용한다
- [ ] H1은 1개, Heading은 계층 순서를 지킨다
- [ ] 메타 디스크립션은 글마다 고유하게, 155자 이내로 쓴다
