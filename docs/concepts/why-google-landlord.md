# 왜 구글 건물주인가

> 남의 땅에서 전세살이 그만하고, 내 건물을 짓자.\
> — 글 1개 = 월세 1건. 자고 있어도 들어오는 시스템.

---

## 0. 먼저, "구글 건물주"가 뭔가요?

아주 간단합니다:

1. **인터넷에 나만의 사이트(건물)를 만든다**
2. **글을 쓴다** (이게 세입자)
3. **구글 검색을 통해 사람들이 찾아온다** (이게 트래픽)
4. **방문자에게 광고를 보여주고 수익을 받는다** (이게 월세)

여기서 핵심은 **"내 것"**이라는 겁니다.\
네이버 블로그는 네이버 거예요. 티스토리는 카카오 거고요. 인스타그램은 메타 거예요.\
하지만 우리가 만드는 사이트는 **100% 내 것**입니다.

### 한 줄 정의

> **구글 건물주 = 내 도메인 + 구글 검색 트래픽 + 광고/제휴 수익**\
> 즉, **남의 플랫폼이 아닌 내 자산에서 수익을 만드는 시스템.**

---

## 1. 핵심 비유: 부동산으로 이해하기

블로그를 부동산에 비유하면 모든 게 명확해집니다.

| | 플랫폼 블로그 | 구글 건물주 |
|---|---|---|
| **비유** | 🏢 남의 건물에 전세 | 🏠 내 땅에 내 건물 |
| **대표** | 네이버 블로그, 티스토리, 브런치, 인스타그램 | 나만의 독립 사이트 |
| **소유권** | 플랫폼 것 (내 것 아님!) | 100% 내 자산 |
| **노출** | 플랫폼 알고리즘 맘대로 | 구글에서 영구적으로 상위 노출 |
| **리스크** | 저품질 한 방이면 노출 0 | 내가 삭제 안 하면 영구적 |
| **수익 상한** | 제한적 (애드포스트 단가 낮음) | 무제한 확장 가능 |
| **수익 분배** | 플랫폼이 일부 가져감 | **100% 내가 가져감** |
| **서버비** | 무료 (대신 자유도 없음) | **역시 무료!** (Vercel Hobby) |
| **이전 가능성** | 콘텐츠를 다른 곳으로 못 옮김 | 어디로든 이전 가능 |

> 💡 **"네이버 블로그도 무료인데 뭐가 다른가요?"**\
> 네이버 블로그는 **무료 전세**입니다. 건물주(네이버)가 "나가" 하면 나가야 해요.\
> 구글 건물주는 **내 땅에 내 건물**입니다. 아무도 못 내보냅니다.

### 더 깊은 비유: 자산 vs 부채

회계적으로 보면:

- **플랫폼 블로그** = **시간을 자산으로 바꾸지 못함**\
  글을 써도 → 내 자산이 안 됨 → 플랫폼이 망하면 0
- **구글 건물주** = **시간이 자산으로 누적됨**\
  글을 쓰면 → 내 도메인의 권위(Authority) ↑ → **글 1개가 평생 일함**

## 2. 실제 데이터 — 거짓말 안 합니다

```
📊 구글 건물주 프로젝트 실적
─────────────────────────────
월간 순방문자 (MAU)    200,000+
지난 1년간 신규 글       0건
월 평균 서버비           ₩0
순수익률                99%
─────────────────────────────
```

> **글을 안 써도 매달 20만 명이 찾아옵니다.**\
> 지난 1년간 글 한 개도 안 썼는데 트래픽이 유지됩니다.\
> 왜? 예전에 써놓은 글들이 **구글에서 계속 상위에 있으니까요.**

### 수익 모델 예시 (실제 수치 기반)

월 20만 방문자 기준:

| 수익원 | 예상 월 수익 | 비고 |
|---|---|---|
| 구글 애드센스 | ₩300,000~800,000 | 페이지뷰 × RPM |
| 쿠팡 파트너스 (제휴) | ₩100,000~500,000 | 클릭률·전환율 의존 |
| 아마존 어소시에이트 | ₩50,000~300,000 | 영어 블로그면 더 큼 |
| 디지털 상품 (전자책 등) | ₩0~500,000 | 시도하면 추가 가능 |
| **합계** | **₩450,000~2,100,000** | — |

:::info 솔직한 디스클레이머
위 수치는 **꾸준히 6개월~1년 이상 운영한** 사이트 기준입니다.\
첫 3개월은 거의 0원이라고 보셔야 합니다. 이건 마라톤이지 단거리가 아니에요.
:::

## 3. 플랫폼 전세살이의 위험성 — 실제 사례

"에이, 네이버 블로그 잘 되는 사람도 많잖아요."

맞습니다. **지금은요.**\
하지만 이런 일들이 실제로 있었습니다:

### 😰 사례 1: 네이버 저품질 알고리즘 사건

- 2018년·2020년·2022년 네이버가 알고리즘을 갑자기 바꿨습니다
- **3년 동안 매일 글 쓴 사람이 하루 만에 노출 0**이 됐습니다
- 구제 방법? 없습니다. 네이버 고객센터에 문의해도 "자체 알고리즘"이라는 답만 옵니다
- 내 데이터의 소유권도 없습니다 — 네이버 약관상 네이버에 라이선스를 부여한 상태입니다

### 😰 사례 2: 티스토리 정책 변경

- 2022년 카카오가 광고 정책을 바꿨습니다 → 기존 수익자들의 수익이 절반으로
- 2023년 카카오데이터센터 화재로 며칠 동안 모든 티스토리 다운
- 만약 카카오가 서비스를 접으면? → **모든 것이 사라집니다**

### 😰 사례 3: 인스타그램·페이스북 도달률 폭락

- 인스타그램은 자체 알고리즘으로 팔로워 도달률을 1~5%로 떨어뜨렸습니다
- 옛날엔 팔로워 1만 명이면 1만 명이 봤습니다. 지금은 100~500명만 봅니다
- 즉, **유료 광고를 사야** 도달이 됩니다 → 플랫폼 종속

### 😰 사례 4: 브런치 (수익 모델 부재)

- 브런치는 아예 직접적인 광고 수익이 없습니다
- 콘텐츠 이전 기능도 없습니다 — 내 글을 다른 곳으로 옮길 수가 없어요
- "브런치 작가" 타이틀은 멋지지만, 그게 끝입니다

### 공통점이 뭔가요?

> **건물주(플랫폼)가 마음 바꾸면, 세입자(여러분)는 속수무책입니다.**\
> 그래서 내 건물을 지어야 합니다.

## 4. 내 건물의 장점 5가지 (디테일)

### 1. ✅ 완전한 소유권

코드도 내 것, 데이터도 내 것, 트래픽도 내 것.\
누구도 내 사이트를 내릴 수 없습니다.

- **법적 소유권**: 도메인을 내가 등록 → 법적으로 내 자산
- **콘텐츠 라이선스**: 글의 저작권은 100% 본인. 어느 플랫폼도 라이선스 없음
- **이전 가능성**: Vercel이 싫으면 → Netlify, Cloudflare Pages로 5분 안에 이전 가능
- **백업**: GitHub에 자동으로 코드와 글이 백업됨

네이버가 망해도, 카카오가 망해도, **내 사이트는 살아있습니다.**

### 2. ✅ 영구적인 상위 노출

구글 검색에 최적화해놓으면, 한 번 올라간 글은 **계속 유지**됩니다.

| | 네이버 블로그 | 구글 SEO 사이트 |
|---|---|---|
| 글의 노출 기간 | 2~4주 | **수년** |
| 한 번 1위 = | 일주일 유지 | 6개월~수년 유지 |
| 알고리즘 변화 시 | 자주 흔들림 | 상대적으로 안정적 |
| 내가 안 만져도 | 노출 자연감소 | 노출 유지 (Authority 효과) |

네이버 블로그는 글을 올리면 2~4주 반짝하고 사라집니다.\
구글은? 제 글 중에 **3년 전에 쓴 게 아직도 1페이지**에 있습니다.

### 3. ✅ 비용 0원 (정확히)

| 항목 | 비용 | 비고 |
|---|---|---|
| **GitHub** (코드 저장) | ₩0 | 무제한 무료 |
| **Vercel** (호스팅) | ₩0 | Hobby 플랜, 월 100GB 트래픽 무료 |
| **Turso** (DB) | ₩0 | 무료 500MB, 1B 행 읽기/월 |
| **HTTPS 인증서** | ₩0 | Vercel이 자동 발급 |
| **도메인** (선택) | ₩15,000/년 | 없어도 시작 가능 (.vercel.app 사용) |
| **Claude Pro** | $20/월 | 약 ₩27,000/월 (AI 코딩) |
| **Gemini API** | ₩0 | 무료 티어로 충분 |

> 합계: **월 ₩27,000** (Claude Pro만)\
> 도메인 ₩15,000/년 추가하면 월 ₩28,250.

비교: 카페 라떼 3잔 값입니다.

### 4. ✅ 무제한 확장성

플랫폼 블로그는 수익 모델이 **딱 정해져 있습니다.**\
내 사이트는? 원하는 만큼 추가할 수 있어요.

- 구글 애드센스 (기본 광고 수익)
- 제휴 마케팅 (쿠팡 파트너스, 아마존 어소시에이트, 자체 제휴)
- 디지털 상품 판매 (전자책, 강의, 템플릿)
- 뉴스레터 구독 (Substack 연동)
- 멤버십 (월정액 콘텐츠)
- 컨설팅·코칭 (트래픽 = 잠재 고객)
- 자체 SaaS 출시 (이미 사이트는 있으니 마케팅 비용 0)

### 5. ✅ 검색 = 의도가 분명한 사용자

이게 사실 가장 큰 차이입니다.

- **인스타그램·페이스북 방문자** → "그냥 둘러보고 있음" (이탈률 90%+)
- **구글 검색 방문자** → "이 문제를 해결하고 싶어서 왔음" (구매 의도 ↑)

**검색 트래픽 = 돈이 되는 트래픽**입니다.\
같은 1000명이라도 구글 검색 1000명이 인스타 1000명보다 10배 가치 있습니다.

## 5. 글의 수명 — 이게 가장 중요합니다

### 네이버 블로그 글의 수명
```
트래픽 ↑
      │  ╱╲
      │ ╱  ╲──── 2~4주 후 사라짐
      │╱    ╲
      └──────────── 시간 →
```
글을 올리면 2~4주 반짝하고, 트래픽 0. 또 써야 합니다.\
**노동집약적**이에요. 글 안 쓰면 수입 0.

### 구글 SEO 글의 수명
```
트래픽 ↑
      │            ╱────── 6개월~ 수년 유지!
      │          ╱
      │        ╱
      │      ╱
      │    ╱
      └──────────── 시간 →
```
처음 1~2달은 천천히 올라갑니다 (구글이 사이트를 알아보는 시간).\
한 번 올라가면? 6개월, 1년, 3년... **계속** 트래픽이 들어옵니다.

### 복리 효과 — 가장 놀라운 부분

글이 쌓이면 **복리**처럼 트래픽이 증가합니다.

| 글 수 | 예상 월 트래픽 | 비유 |
|---|---|---|
| 10개 | 500~1,000명 | 원룸 건물 |
| 30개 | 3,000~5,000명 | 소형 빌딩 |
| 50개 | 10,000~20,000명 | 중형 빌딩 |
| 100개 | 50,000명+ | 대형 빌딩 |
| 200개+ | 200,000명+ | 본 강의자 수준 |

왜 비선형(복리)으로 증가하느냐:
- 글이 많아질수록 → 내부 링크가 늘어남 → 사이트 권위(Authority) 상승
- 사이트 권위가 상승하면 → 신규 글도 빨리 상위 노출
- 신규 글이 상위 노출되면 → 기존 글에도 트래픽 전달 (내부 링크 효과)

> **글 1개 = 월세 1건입니다.**\
> 글이 쌓일수록 월세가 늘어납니다. 이게 "건물주"의 본질이에요.

## 6. "그럼 누구나 다 해야 하나요?" — 솔직한 답

### ✅ 이 프로젝트가 잘 맞는 사람

- 코딩에 알레르기 있지만, 시스템·자산 만들고 싶은 분
- 한 번 만들고 **꾸준히 가꾸는** 마인드가 있는 분
- 6개월~1년 결과 안 나와도 **버틸 인내심**이 있는 분
- 자기 분야의 **전문 지식·관심사**가 있는 분
- AI 시대의 **콘텐츠 자산화**에 관심 있는 분

### ❌ 안 맞는 사람

- **이번 달부터 월 100만 원 벌고 싶다** → 무리. 다른 거 알아보세요
- **한 달 안에 결과 안 나오면 포기** → 안 됩니다. 최소 6개월
- **글 쓰기 자체가 너무 싫다** → AI가 도와줘도 검수는 본인이 해야 함
- **단기 알바·부업이 더 좋다** → 시간 대비 즉시 수익은 알바가 더 큽니다

> 단기 수익 vs 자산 형성 — 이 차이를 이해하면 결정이 쉬워요.\
> 알바는 **시간을 돈으로** 바꿉니다 (1회성).\
> 이건 **시간을 자산으로** 바꿉니다 (영구적).

---

## 7. 한 줄 요약

> **네이버에서 전세살이 하던 시간에, 구글에 내 건물 짓자.**\
> 서버비 0원, 소유권 100%, 글 하나가 월세를 내는 시스템.\
> 단, 6개월 이상 꾸준한 사람만 결실을 봅니다.
