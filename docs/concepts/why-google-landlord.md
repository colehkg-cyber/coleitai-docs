# 왜 구글 건물주인가 (1) — 개념과 비교

> 남의 땅에서 전세살이 그만하고, 내 건물을 짓자.\
> — 1편: 구글 건물주가 뭔지, 왜 플랫폼 블로그보다 나은지.

---

## 0. 먼저, "구글 건물주"가 뭔가요?

아주 간단합니다:

1. **인터넷에 나만의 사이트(건물)를 만든다**
2. **글을 쓴다** (이게 세입자)
3. **구글 검색을 통해 사람들이 찾아온다** (이게 트래픽)
4. **방문자에게 광고를 보여주고 수익을 받는다** (이게 월세)

여기서 핵심은 **"내 것"**이라는 겁니다.\
네이버 블로그는 네이버 거예요. 티스토리는 카카오 거고요. 인스타그램은 메타 거예요.\
하지만 우리가 만드는 사이트는 **100% 내 것**입니다.

### 한 줄 정의

> **구글 건물주 = 내 도메인 + 구글 검색 트래픽 + 광고/제휴 수익**\
> 즉, **남의 플랫폼이 아닌 내 자산에서 수익을 만드는 시스템.**

---

## 1. 핵심 비유: 부동산으로 이해하기

블로그를 부동산에 비유하면 모든 게 명확해집니다.

| | 플랫폼 블로그 | 구글 건물주 |
|---|---|---|
| **비유** | 🏢 남의 건물에 전세 | 🏠 내 땅에 내 건물 |
| **대표** | 네이버 블로그, 티스토리, 브런치, 인스타그램 | 나만의 독립 사이트 |
| **소유권** | 플랫폼 것 (내 것 아님!) | 100% 내 자산 |
| **노출** | 플랫폼 알고리즘 맘대로 | 구글에서 영구적으로 상위 노출 |
| **리스크** | 저품질 한 방이면 노출 0 | 내가 삭제 안 하면 영구적 |
| **수익 상한** | 제한적 (애드포스트 단가 낮음) | 무제한 확장 가능 |
| **수익 분배** | 플랫폼이 일부 가져감 | **100% 내가 가져감** |
| **서버비** | 무료 (대신 자유도 없음) | **역시 무료!** (Vercel Hobby) |
| **이전 가능성** | 콘텐츠를 다른 곳으로 못 옮김 | 어디로든 이전 가능 |

> 💡 **"네이버 블로그도 무료인데 뭐가 다른가요?"**\
> 네이버 블로그는 **무료 전세**입니다. 건물주(네이버)가 "나가" 하면 나가야 해요.\
> 구글 건물주는 **내 땅에 내 건물**입니다. 아무도 못 내보냅니다.

### 더 깊은 비유: 자산 vs 부채

회계적으로 보면:

- **플랫폼 블로그** = **시간을 자산으로 바꾸지 못함**\
  글을 써도 → 내 자산이 안 됨 → 플랫폼이 망하면 0
- **구글 건물주** = **시간이 자산으로 누적됨**\
  글을 쓰면 → 내 도메인의 권위(Authority) ↑ → **글 1개가 평생 일함**

## 2. 실제 데이터 — 거짓말 안 합니다

```
📊 구글 건물주 프로젝트 실적
─────────────────────────────
월간 순방문자 (MAU)    200,000+
지난 1년간 신규 글       0건
월 평균 서버비           ₩0
순수익률                99%
─────────────────────────────
```

> **글을 안 써도 매달 20만 명이 찾아옵니다.**\
> 지난 1년간 글 한 개도 안 썼는데 트래픽이 유지됩니다.\
> 왜? 예전에 써놓은 글들이 **구글에서 계속 상위에 있으니까요.**

### 수익 모델 예시 (실제 수치 기반)

월 20만 방문자 기준:

| 수익원 | 예상 월 수익 | 비고 |
|---|---|---|
| 구글 애드센스 | ₩300,000~800,000 | 페이지뷰 × RPM |
| 쿠팡 파트너스 (제휴) | ₩100,000~500,000 | 클릭률·전환율 의존 |
| 아마존 어소시에이트 | ₩50,000~300,000 | 영어 블로그면 더 큼 |
| 디지털 상품 (전자책 등) | ₩0~500,000 | 시도하면 추가 가능 |
| **합계** | **₩450,000~2,100,000** | — |

:::info 솔직한 디스클레이머
위 수치는 **꾸준히 6개월~1년 이상 운영한** 사이트 기준입니다.\
첫 3개월은 거의 0원이라고 보셔야 합니다. 이건 마라톤이지 단거리가 아니에요.
:::

## 3. 플랫폼 전세살이의 위험성 — 실제 사례

"에이, 네이버 블로그 잘 되는 사람도 많잖아요."

맞습니다. **지금은요.**\
하지만 이런 일들이 실제로 있었습니다:

### 😰 사례 1: 네이버 저품질 알고리즘 사건

- 2018년·2020년·2022년 네이버가 알고리즘을 갑자기 바꿨습니다
- **3년 동안 매일 글 쓴 사람이 하루 만에 노출 0**이 됐습니다
- 구제 방법? 없습니다. 네이버 고객센터에 문의해도 "자체 알고리즘"이라는 답만 옵니다
- 내 데이터의 소유권도 없습니다 — 네이버 약관상 네이버에 라이선스를 부여한 상태입니다

### 😰 사례 2: 티스토리 정책 변경

- 2022년 카카오가 광고 정책을 바꿨습니다 → 기존 수익자들의 수익이 절반으로
- 2023년 카카오데이터센터 화재로 며칠 동안 모든 티스토리 다운
- 만약 카카오가 서비스를 접으면? → **모든 것이 사라집니다**

### 😰 사례 3: 인스타그램·페이스북 도달률 폭락

- 인스타그램은 자체 알고리즘으로 팔로워 도달률을 1~5%로 떨어뜨렸습니다
- 옛날엔 팔로워 1만 명이면 1만 명이 봤습니다. 지금은 100~500명만 봅니다
- 즉, **유료 광고를 사야** 도달이 됩니다 → 플랫폼 종속

### 😰 사례 4: 브런치 (수익 모델 부재)

- 브런치는 아예 직접적인 광고 수익이 없습니다
- 콘텐츠 이전 기능도 없습니다 — 내 글을 다른 곳으로 옮길 수가 없어요
- "브런치 작가" 타이틀은 멋지지만, 그게 끝입니다

### 공통점이 뭔가요?

> **건물주(플랫폼)가 마음 바꾸면, 세입자(여러분)는 속수무책입니다.**\
> 그래서 내 건물을 지어야 합니다.
