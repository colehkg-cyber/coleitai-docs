> 1편에서 SEO의 정의와 구글의 작동 원리를 봤습니다.\
> 2편에서는 URL 구조, 스니펫, 사이트맵, robots.txt 같은 **실전 기법**을 다룹니다.

## 6. URL 구조 — 의외로 중요합니다

URL은 사람과 구글 모두에게 **첫 인상**입니다.\
구글 공식 가이드는 URL에 대해 다음 원칙을 제시합니다.

### ✅ 좋은 URL

```
✅ https://myblog.com/seo/google-landlord-basics
✅ https://myblog.com/blog/2024/seo-guide
✅ https://myblog.com/category/post-name
```

특징:
- 의미를 알 수 있는 단어 사용
- 단어는 하이픈(`-`)으로 구분
- 짧고 명확함
- 카테고리 구조가 명확함

### ❌ 나쁜 URL

```
❌ https://myblog.com/?p=12345
❌ https://myblog.com/post_123_final_FINAL_v2
❌ https://myblog.com/한글-포함-URL  (검색엔진은 인코딩으로 봄)
❌ https://myblog.com/blog/2024/01/15/post-name-extremely-long-with-many-words
```

문제점:
- 의미 없는 숫자 ID
- 언더스코어(`_`) 사용 — 구글은 하이픈을 선호
- 한글 URL은 인코딩되어 알아보기 어려움
- 너무 긴 경로

### URL 구조 원칙

| 원칙 | 예시 |
|---|---|
| **소문자 사용** | `/seo-guide` (O) vs `/SEO-Guide` (X) |
| **하이픈 사용** | `/google-landlord` (O) vs `/google_landlord` (X) |
| **의미 있는 단어** | `/seo-basics` (O) vs `/post-1234` (X) |
| **짧게** | `/blog/seo-tips` (O) vs `/blog/category/2024/01/15/post` (X) |
| **영문 사용** | `/korean-seo` (O) vs `/한국-seo` (X) |

> 💡 우리 템플릿은 글 제목으로 자동 슬러그(URL 경로)를 생성합니다.\
> 한글 제목 → 영문 슬러그로 변환됩니다.

### URL을 바꾸면 안 되는 이유

이미 발행한 글의 URL을 변경하면 **모든 SEO 점수가 리셋**됩니다.

| 상황 | 결과 |
|---|---|
| URL 변경 + 리다이렉트 없음 | 404 오류 → 검색 결과 노출 0 |
| URL 변경 + 301 리다이렉트 | 90% 점수 유지 (권장) |
| URL 그대로 유지 | 100% 점수 유지 (최선) |

> ⚠️ URL은 **처음 정할 때 신중**하게. 한 번 정하면 가능한 바꾸지 마세요.

## 7. 스니펫(Snippets) — 검색 결과 한 줄

검색 결과에서 제목 아래 표시되는 **요약 텍스트**를 스니펫이라고 합니다.

```
┌─────────────────────────────────────────────┐
│ SEO 기초 — 구글이 어떻게 작동하는가          │ ← 제목 (title)
│ https://myblog.com/seo-basics                │ ← URL
│ 구글 검색은 크롤링, 색인, 게재의 3단계로... │ ← 스니펫 (description)
└─────────────────────────────────────────────┘
```

### 스니펫 생성 방식

구글은 **두 가지 중 하나**를 자동으로 선택합니다:

1. **메타 디스크립션** (`<meta name="description">`) — 내가 직접 지정
2. **페이지 본문 일부** — 구글이 자동 발췌

> 💡 구글은 검색어에 따라 다른 부분을 보여줄 수도 있습니다.\
> 메타 디스크립션을 써도 항상 보여주는 건 아닙니다.

### 좋은 메타 디스크립션

| 항목 | 권장 |
|---|---|
| **길이** | 120~160자 (모바일은 더 짧게 잘림) |
| **고유성** | 페이지마다 다르게 |
| **요약성** | 본문의 핵심을 한두 문장으로 |
| **클릭 유도** | 명사보다 동사·질문형 |
| **키워드 포함** | 자연스럽게 (스터핑 금지) |

### 예시 비교

✅ **좋은 메타 디스크립션**
```html
<meta name="description"
  content="구글 검색이 작동하는 방식을 3단계로 설명합니다.
  크롤링·색인·게재의 흐름과 E-E-A-T 기준을 알면
  내 글이 왜 노출되는지 이해할 수 있습니다.">
```

❌ **나쁜 메타 디스크립션**
```html
<!-- 너무 짧음 -->
<meta name="description" content="SEO 가이드">

<!-- 키워드 스터핑 -->
<meta name="description"
  content="SEO SEO 최적화 구글 SEO 네이버 SEO 블로그 SEO
  검색 최적화 SEO 가이드 SEO 튜토리얼 SEO 강의">

<!-- 모든 페이지가 동일 -->
<meta name="description" content="우리 블로그에 오신 걸 환영합니다">
```

> 💡 우리 템플릿은 글의 첫 문단을 자동으로 메타 디스크립션으로 사용합니다.\
> 또는 frontmatter에 `description:` 필드로 직접 지정할 수도 있습니다.

## 8. 추천 스니펫 (Featured Snippets) — 0위의 자리

검색 결과 **맨 위, 1위보다 위**에 박스 형태로 표시되는 답변입니다.\
구글이 "이게 정답이야"라고 선택한 콘텐츠입니다.

### 추천 스니펫 종류

| 종류 | 형태 | 예시 검색어 |
|---|---|---|
| **단락형** | 한 문단 답변 | "SEO란?" |
| **목록형** | 순서 있는/없는 리스트 | "블로그 만드는 방법" |
| **표형** | 비교표 | "iPhone 15 vs 16" |
| **영상형** | YouTube 영상 | "리액트 시작하기" |

### 추천 스니펫에 선정되는 법

1. **질문에 직접 답하는 문장**을 글 초반에 배치
   ```markdown
   ## SEO란 뭔가요?

   SEO는 검색엔진이 내 콘텐츠를 잘 이해하도록 돕고,
   사람들이 내 사이트를 방문하도록 만드는 모든 작업입니다.
   ```

2. **40~60 단어** 정도의 간결한 답변
3. **H2, H3 헤딩으로 질문**을 그대로 사용
4. **표·리스트** 구조 적극 활용
5. 이미 **1페이지 진입**한 글에서 잘 선정됨

> 💡 추천 스니펫에 선정되면 **CTR(클릭률)이 2~8배** 올라갑니다.

## 9. 사이트맵 (sitemap.xml) — 구글에게 보내는 지도

사이트맵은 **내 사이트의 모든 페이지 목록**을 담은 XML 파일입니다.

### 사이트맵이 필요한 이유

| 이유 | 설명 |
|---|---|
| **빠른 발견** | 구글이 새 글을 더 빨리 찾음 |
| **누락 방지** | 내부 링크가 약한 페이지도 색인 |
| **신생 사이트** | 외부 링크가 없을 때 필수 |
| **대형 사이트** | 페이지가 100개 이상이면 필수 |

### 사이트맵 예시

```xml
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://myblog.com/</loc>
    <lastmod>2025-05-01</lastmod>
    <changefreq>daily</changefreq>
    <priority>1.0</priority>
  </url>
  <url>
    <loc>https://myblog.com/seo-basics</loc>
    <lastmod>2025-04-15</lastmod>
    <changefreq>weekly</changefreq>
    <priority>0.8</priority>
  </url>
</urlset>
```

### 사이트맵 제출 방법

1. 자동 생성: 우리 템플릿은 `next-sitemap`으로 자동 생성
2. URL 확인: `https://myblog.com/sitemap.xml`
3. Google Search Console에서 제출:
   - 좌측 메뉴 → **Sitemaps**
   - URL 입력 → **제출**

> 💡 사이트맵은 한 번만 제출하면 끝.\
> 이후 구글이 주기적으로 다시 가져갑니다.

## 10. robots.txt — 구글 봇에게 주는 규칙

`robots.txt`는 구글봇이 **어디는 가도 되고, 어디는 가면 안 되는지**를 알려주는 텍스트 파일입니다.

### 위치

```
https://myblog.com/robots.txt
```

루트 도메인에 **반드시** 위치해야 합니다.

### 기본 예시

```txt
# 모든 봇에게 모든 페이지 허용
User-agent: *
Allow: /

# 사이트맵 위치 알려주기
Sitemap: https://myblog.com/sitemap.xml
```

### 차단이 필요한 경우

```txt
User-agent: *
# 관리자 페이지 차단
Disallow: /admin/

# 검색 결과 페이지 차단 (중복 콘텐츠 방지)
Disallow: /search?

# 로그인 페이지 차단
Disallow: /login

# AI 크롤러 차단 (선택)
User-agent: GPTBot
Disallow: /

User-agent: Google-Extended
Disallow: /
```

### 흔한 실수

| 실수 | 결과 |
|---|---|
| `Disallow: /` | 전체 사이트 색인 차단됨 (재앙) |
| robots.txt 누락 | 모든 봇이 모든 곳 접근 (괜찮음) |
| 대소문자 혼동 | `disallow`와 `Disallow`는 동일 |
| 한글 경로 미인코딩 | 작동 안 함 |

> ⚠️ `Disallow: /`는 **사이트 전체를 검색에서 숨김**.\
> 절대 실수로 넣지 마세요.

### robots.txt vs noindex

| | robots.txt | noindex |
|---|---|---|
| 어디서 차단 | 크롤링 자체 | 색인만 |
| 검색 노출 | 막을 수 없음 (이미 색인된 건) | 확실히 안 보임 |
| 사용 시점 | 크롤 예산 절약 | 페이지를 검색에서 빼고 싶을 때 |

> 💡 **검색에서 완전히 빼려면 `noindex`를 쓰세요.**\
> robots.txt는 크롤링만 막을 뿐, 색인을 막지는 못합니다.

## 11. 발행 전 체크리스트 — 글 올리기 전 마지막 점검

매 글마다 **이 체크리스트**를 돌리는 습관을 들이세요.

### 콘텐츠

- [ ] 검색 의도에 맞는 제목인가?
- [ ] 본문 500자 이상인가? (얇은 콘텐츠 방지)
- [ ] 한 주제에 집중되어 있나?
- [ ] 1차 자료(직접 경험, 측정값, 인터뷰)가 있나?
- [ ] 출처가 명확한가?
- [ ] 오탈자·문법 점검했나?

### 구조

- [ ] H1은 한 개뿐인가? (페이지 제목)
- [ ] H2 → H3 헤딩 위계가 자연스러운가?
- [ ] 단락이 너무 길지 않은가? (3~5줄)
- [ ] 표·리스트로 가독성을 높였는가?
- [ ] 이미지에 alt 텍스트가 있나?

### 메타데이터

- [ ] 제목(title)이 60자 이내?
- [ ] 메타 디스크립션이 120~160자?
- [ ] URL 슬러그가 짧고 의미 있나?
- [ ] 발행 날짜가 표시되나?
- [ ] 카테고리/태그가 적절한가?

### 링크

- [ ] 내 사이트 내 관련 글로 **내부 링크** 1~3개?
- [ ] 권위 있는 외부 사이트로 **외부 링크** 1~2개?
- [ ] 모든 링크가 깨지지 않나?
- [ ] 외부 링크에 `rel="noopener"` 적용?

### 기술

- [ ] 모바일에서 잘 보이나?
- [ ] 페이지 로딩이 3초 이내?
- [ ] HTTPS로 접속 가능?
- [ ] 사이트맵에 추가됐나? (자동)

### 자가 진단

- [ ] **Who**: 누가 썼는지 명확한가?
- [ ] **How**: 어떻게 만들었는지 (직접 경험·AI 활용 등) 밝혔나?
- [ ] **Why**: 사람을 돕기 위해서인가?

> 💡 우리 템플릿은 위 항목 중 **70%를 자동 처리**합니다.\
> 사람이 신경 써야 할 건: **콘텐츠 + 자가 진단**.

## 12. 한 줄 요약

> **SEO는 트릭이 아니라 원칙입니다.**\
> 구글의 3단계(크롤·색인·게재)를 이해하고,\
> E-E-A-T로 사람을 위해 쓰면, **시간이 알아서 답을 줍니다.**

### 세 줄 정리

1. 사람을 위한 콘텐츠를 쓰자 (E-E-A-T)
2. 기술적 기본기를 빠뜨리지 말자 (URL·메타·사이트맵)
3. **꾸준히, 6개월 이상**
