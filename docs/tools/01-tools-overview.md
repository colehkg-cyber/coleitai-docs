# 1강. 도구 한눈에 보기

> **이 강의에서 배울 것**
> 6가지 도구가 각자 어떤 역할을 하고, 어떻게 서로 연결되어서 블로그가 인터넷에 뜨는지 **전체 그림**을 그립니다.
> 깊은 내용은 2강부터, 여기서는 **숲을 먼저**.

---

## 카페 비유로 단숨에

블로그 운영은 **카페를 차리고 운영하는 것**과 똑같습니다.

| 도구 | 카페로 치면 | 무엇을 함 |
|---|---|---|
| **Claude** | 똑똑한 알바생 | 사장님 대신 메뉴(=코드) 만듦 |
| **GitHub** | 레시피 노트 | 메뉴 레시피(=코드) 모두 기록·보관 |
| **Vercel** | 매장 | 손님(=방문자)이 실제로 들어오는 공간 |
| **Turso** | 장부 | 글·매출(=조회수) 기록 |
| **Gemini** | 작가 알바 | 메뉴 설명문(=블로그 글) 작성 |
| **VS Code** | 주방·작업대 | 사장님이 직접 작업하는 책상 |

글 발행·키워드 등록·통계는 **블로그 템플릿에 내장된 `/admin` 패널**에서 처리합니다 (외부 도구 X, 가입 X).

> 💡 사장님 = 나
> 메뉴·레시피 = 블로그 코드
> 매장 손님 = 블로그 방문자

## 각 도구 한 줄 요약

### 1. Claude
> "AI 알바생. 내 컴퓨터에서 코드 직접 읽고 수정."

ChatGPT의 경쟁사 Anthropic이 만든 AI. **Claude Code**라는 도구로 터미널에서 명령 한 줄이면, AI가 내 폴더 안에 있는 코드를 **직접 읽고 직접 고쳐** 줍니다. 100시간 배울 일을 1시간에 끝내줍니다.

### 2. GitHub
> "코드용 구글 드라이브. 변경 이력 무한 보관."

내가 코드를 바꿀 때마다 자동으로 기록. 망쳐도 과거로 되돌리기. 개인 사용 평생 무료. 전 세계 개발자가 다 씁니다.

### 3. Vercel
> "코드를 인터넷에 자동으로 띄워주는 매장."

GitHub에 코드를 올리면 **30초 안에 인터넷 주소**로 만들어 줍니다. 도메인·HTTPS 자물쇠·CDN(빠른 전송) 전부 자동. 개인 블로그 평생 무료.

### 4. Turso
> "블로그 글 저장하는 클라우드 엑셀."

블로그 글·조회수를 저장하는 데이터베이스(DB). 9GB까지 무료(블로그로는 못 채움).

### 5. Gemini
> "구글이 만든 AI 작가. 키워드만 주면 글 써줌."

Gemini API를 받아 두면, 블로그가 키워드를 보고 자동으로 글을 생성합니다. 카드 등록 없이 무료.

### 6. VS Code
> "코드 편집기. 마이크로소프트가 만든 무료 도구."

내 컴퓨터에서 코드를 열어보고 고치는 프로그램. Claude Code도 여기 안에서 실행됩니다.

## 전체 흐름 도식

```
                  ┌──────────────┐
                  │   Claude     │ ← AI에게 시킴
                  │  (알바 AI)   │
                  └──────┬───────┘
                         │ 코드 작성
                         ▼
   ┌─────────────────────────────────┐
   │       내 컴퓨터 (VS Code)        │  ← 내가 작업
   └────────────────┬────────────────┘
                    │ git push
                    ▼
              ┌──────────┐
              │  GitHub  │  ← 코드 영구 보관
              └─────┬────┘
                    │ 자동 감지(웹훅)
                    ▼
              ┌──────────┐
              │  Vercel  │  ← 인터넷에 공개
              └─────┬────┘
                    │ 실행 중 호출
              ┌─────┴──────┐
              ▼            ▼
          ┌──────┐    ┌────────┐
          │Turso │    │ Gemini │
          │ (DB) │    │  (AI)  │
          └──────┘    └────────┘

  글 발행·키워드 등록은 블로그 내장 `/admin` 패널에서.
```

**한 문장 요약**: Claude가 코드 작성 → GitHub 보관 → Vercel이 인터넷에 띄움 → 손님이 와서 Turso·Gemini를 사용.

## 자주 묻는 질문

**Q. Claude·Gemini·ChatGPT 다 AI인데 왜 두 개나 쓰나요?**
- Claude → **코드** 작성 (개발자처럼 잘함)
- Gemini → **블로그 글** 작성 (글쓰기 무료 API 제공)
- 역할이 달라서 둘 다 씁니다.

**Q. 워드프레스 vs 이 블로그 — 차이는?**
- 워드프레스: 서버 비용 매월, 플러그인 충돌, 느림
- 이 블로그(Next.js + Vercel): **무료, 빠름**, 코드 100% 내 것

**Q. 한꺼번에 6개 다 외워야 하나요?**
- 아니요. 각 도구를 **한 줄 정의**만 외우면 충분합니다.
- 2~7강에서 한 도구씩 차근차근.
