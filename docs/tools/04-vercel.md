# 4강. Vercel — 인터넷 매장

> **이 강의에서 배울 것**
> "코드를 인터넷에 띄운다"는 게 뭔지, Vercel이 그걸 어떻게 30초 만에 해주는지, 도메인·HTTPS·CDN 같은 단어가 뭔지 이해합니다.

---

## Vercel이 뭐예요?

> 👉 **GitHub에 올려둔 블로그 코드를 → 인터넷 주소로 자동 변환해주는 회사.**

쉽게 말해 **"내 카페 매장"**.

| 비유 | 실제 |
|---|---|
| 카페 매장 (손님이 들어오는 공간) | Vercel |
| 카페 주소 | 내 블로그 URL (예: myblog.vercel.app) |
| 카페 인테리어·메뉴판 | 블로그 코드 |
| 카페 간판 | 도메인 |

---

## 왜 필요한가요?

내 컴퓨터에서만 돌아가는 코드는 **나만 볼 수 있습니다.**
다른 사람에게 보여주려면 24시간 켜져 있는 서버가 필요해요.

옛날에는:
- 서버 컴퓨터 직접 구매 → 매월 전기·인터넷 비용
- 또는 호스팅 회사 임대 → 매월 1~5만원

지금은:
- **Vercel에 GitHub 연결 → 무료, 자동, 빠름**

---

## 핵심 용어 풀이

블로그 배포할 때 만나는 단어들을 미리 풀어 둡니다.

### 1. 배포 (Deploy)
> "내 코드를 인터넷에 올려서 모두가 볼 수 있게 하는 작업."
예: "Vercel에 배포했다" = "내 블로그가 인터넷에 떴다"

### 2. 빌드 (Build)
> "원본 코드를 → 브라우저가 빠르게 읽을 수 있는 형태로 변환하는 작업."

| 원본 | 빌드 후 |
|---|---|
| React/Next.js 소스 코드 | HTML, CSS, JS 파일 |
| 사람이 읽기 쉬움 | 컴퓨터가 빠르게 처리 가능 |

Vercel이 **GitHub의 코드 → 자동으로 빌드 → 인터넷에 배포** 까지 한 번에.

### 3. 도메인 (Domain)
> "인터넷 주소 이름."
예: `google.com`, `naver.com`, `myblog.com`

- Vercel 무료 주소: `myblog.vercel.app` ← 처음엔 이걸로 시작
- 내 도메인 사기: 가비아·후이즈 등에서 연 1~2만원, 나중에 연결 가능

### 4. HTTPS (자물쇠 🔒)
> "주소창에 자물쇠 모양이 뜨는 보안 통신."
- HTTP → 도청 가능 (해커가 정보 훔침)
- HTTPS → 암호화됨 (안전)

Vercel은 **자동으로 HTTPS** 적용. 옛날엔 직접 인증서 사야 했음.

### 5. CDN (Content Delivery Network)
> "전 세계 곳곳에 내 블로그 복사본을 배치해 두는 시스템."

비유: 떡볶이 가게가 서울에만 있으면 부산 사람은 멀어요. 그래서 부산·대구·광주에도 매장 만듦 → 모두가 빠르게.

Vercel은 전 세계 30개 이상 도시에 자동 분산. 한국 사람은 한국 서버, 미국 사람은 미국 서버에서 받음.

### 6. 환경변수 (Environment Variable)
> "코드에 직접 적기 싫은 비밀 값 (API 키, DB 비밀번호 등)을 따로 저장하는 곳."

예시:
- ❌ 코드에 적기: `apiKey = "sk-1234-비밀키"` → GitHub에 노출됨
- ✅ 환경변수에 적기: Vercel 설정 페이지 → 코드는 `apiKey = process.env.MY_KEY`

## 작동 흐름

```
   내 컴퓨터에서 코드 수정
            ↓
       git push (저장)
            ↓
   ┌────────────────┐
   │     GitHub     │  ← 코드 도착
   └───────┬────────┘
           │ 웹훅(자동 신호)
           ▼
   ┌────────────────┐
   │     Vercel     │
   │  1. 코드 다운   │
   │  2. 빌드        │
   │  3. 배포        │
   └───────┬────────┘
           ▼
     CDN에 복사본 배포
           ↓
   ┌────────────────┐
   │  내 블로그 공개  │  ← myblog.vercel.app
   └────────────────┘

   소요 시간: 약 30초~1분
```

## Vercel의 무료 한도

| 항목 | 무료 한도 | 우리가 쓸 양 |
|---|---|---|
| 배포 횟수 | 무제한 | OK |
| 트래픽 (방문자) | 월 100GB | 월 1만 방문 이내 충분 |
| 빌드 시간 | 월 6,000분 | 1회 1분 × 100회 = 100분, 충분 |
| 함수 실행 | 월 100만 호출 | 충분 |

> 개인 블로그로는 **평생 무료** 가능.

## 자주 묻는 질문

**Q. Vercel 말고 다른 곳은 없나요?**
| 서비스 | 특징 |
|---|---|
| **Vercel** | Next.js 만든 회사. 한국 빠름. 우리가 씀. |
| Netlify | 비슷. 정적 사이트 강함. |
| Cloudflare Pages | 무료 한도 큼. 설정 약간 어려움. |
| AWS Amplify | 강력하지만 복잡·유료 위험. |

→ 입문자는 **Vercel** 추천.

**Q. 회사 비밀 코드 올려도 되나요?**
- GitHub Private + Vercel = OK (외부 비공개)
- 다만 우리 블로그는 코드 자체는 공개해도 무방.

**Q. 도메인은 꼭 사야 하나요?**
- 아니요. `myblog.vercel.app` 무료 주소로 평생 가능.
- 브랜드 만들고 싶을 때 사면 됨.

**Q. GitHub 없이 Vercel만 쓸 수 있나요?**
- 가능하지만 비추. **GitHub + Vercel** 조합이 표준.
