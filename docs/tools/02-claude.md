# 도구 1. Claude — AI 알바생

> **이 챕터에서 배우는 것**
> - AI(인공지능)가 도대체 뭔지
> - Claude는 다른 AI랑 뭐가 다른지
> - 가입하고 결제하기
> - "Claude Code"라는 마법 도구 설치하기
> - 처음 말 걸어보기

---

## 1. AI가 뭐예요? — 5분 짜리 설명

### 아주 솔직하게 말하면

AI는 **"엄청 많이 책을 읽은 똑똑한 친구"** 입니다.

```
보통 사람:    1년에 책 10권 읽음
대학교수:     평생 책 5,000권 읽음
AI(Claude):  인터넷에 있는 거의 모든 글을 다 읽었음
```

AI한테 질문하면 → AI가 그동안 읽은 걸 바탕으로 → 가장 그럴듯한 대답을 만들어줍니다.

### 그게 끝이에요?

네, 끝입니다. 영화에 나오는 인공지능 로봇이 아니에요.

> 🤔 **"그럼 왜 다들 난리예요?"**
> 그 "그럴듯한 대답"이 너무 잘 맞아서요. 코드도 짜고, 글도 쓰고, 번역도 합니다. 사람이 한 시간 걸릴 일을 1초만에 합니다.

### 우리가 AI한테 시키는 일

이 강의에서 AI(Claude)에게 시킬 일들:

| 시킬 일 | 우리가 하는 말 | Claude가 해주는 것 |
|---|---|---|
| 블로그 디자인 변경 | "헤더 색깔을 파란색으로 바꿔줘" | CSS 파일을 알아서 찾아서 색 변경 |
| 블로그 글 쓰기 | "맥북 발열에 대한 글 써줘" | 2000자 분량 글 자동 생성 |
| 에러 해결 | "이 에러 어떻게 고쳐?" | 원인 분석 + 해결 코드 제시 |
| 코드 설명 | "이 파일이 뭐 하는 거야?" | 한국어로 풀어서 설명 |

**한국어로 말해도 됩니다.** 코딩 용어 몰라도 됩니다.

## 2. Claude vs 다른 AI — 뭐가 다른가요?

세상에 AI는 많습니다. 왜 하필 Claude일까?

| AI | 만든 회사 | 특징 | 가격 |
|---|---|---|---|
| **Claude** | Anthropic (미국) | 코딩·글쓰기 최강, "Claude Code" 도구 보유 | $20/월 |
| ChatGPT | OpenAI (미국) | 가장 유명, 범용성 좋음 | $20/월 |
| Gemini | Google | 검색 연동 강함, 무료 플랜 좋음 | 무료 ~ 유료 |
| Copilot | Microsoft | VS Code 내장, 코딩 보조 | $10/월 |

### 우리가 Claude를 쓰는 이유 딱 하나

**"Claude Code"** 라는 도구 때문입니다.

다른 AI는 **대화창**에서만 일합니다. 코드를 받으려면:
1. 내 코드를 복사 →
2. AI 대화창에 붙여넣기 →
3. AI가 수정한 코드를 다시 복사 →
4. 내 파일에 붙여넣기

복잡하죠? Claude Code는 다릅니다:

```
1. 터미널에서 "claude" 명령 입력
2. "헤더 색깔 파란색으로 바꿔줘" 한국어 말함
3. Claude가 내 컴퓨터의 파일을 직접 읽고 직접 고침
4. 끝
```

**복붙이 없습니다.** AI가 직접 일합니다. 이게 게임 체인저예요.

:::tip 다른 AI를 이미 쓰고 있다면?
ChatGPT Plus 쓰는 분도, Gemini 쓰는 분도 **Claude Pro는 별개로** 구독하시는 게 좋습니다. Claude Code 때문에요. 한 달 써보고 마음에 안 들면 환불 신청 가능합니다 (7일 이내).
:::

## 3. 가입하기 (3분)

### Step 1. 회원가입

1. 브라우저에서 **[claude.ai](https://claude.ai)** 접속
2. 오른쪽 위 **"Sign up"** 클릭
3. 가입 방법 선택:
   - **Google 계정으로 계속** (가장 쉬움 — 추천 ⭐)
   - 이메일로 가입
4. 가입 완료 → 대화창이 보이면 성공

### Step 2. 한 번 말 걸어보기 (체험)

대화창 아래에 한국어로 입력해보세요:

```
안녕? 너 누구야?
```

→ Claude가 한국어로 자기소개를 합니다.

> 🎉 **여러분이 방금 한 일**: AI한테 인사를 한 겁니다. 이게 시작이에요.

### Step 3. 무료 vs Pro 차이

| 항목 | 무료 | Pro ($20/월) |
|---|---|---|
| 대화 횟수 | 하루 몇 번 | 거의 무제한 |
| 모델 성능 | 기본 모델 | 최신 고성능 모델 |
| **Claude Code 사용** | ❌ | ✅ |
| 대화창 첨부 파일 | ❌ | ✅ |

**우리는 Pro가 필수입니다.** Claude Code를 못 쓰면 이 강의를 못 따라옵니다.

## 4. Pro 결제하기 (2분)

### Step 1. 결제 메뉴 찾기

1. Claude 대화창에서 **왼쪽 아래 본인 이름** 클릭
2. 메뉴에서 **"Settings"** (설정) 클릭
3. 왼쪽 사이드바에서 **"Plans & Billing"** 클릭
4. **"Upgrade to Pro"** (Pro로 업그레이드) 클릭

### Step 2. 카드 등록

1. 결제 정보 입력 화면 → 신용카드 정보 입력
2. **국가**: Korea, Republic of (대한민국)
3. 결제 → 영수증 이메일 도착

### Step 3. Pro 활성화 확인

1. **한 번 로그아웃**했다가 다시 로그인 (이게 중요)
2. 대화창 아래 모델 선택 부분에 **"Claude Opus 4"** 같은 고성능 모델이 보이면 OK

:::warning 환불은 7일 안에만
첫 결제일 기준 **7일 이내**에만 환불 가능합니다. 한 달만 써보고 결정하셔도 됩니다. 환불은 [support.anthropic.com](https://support.anthropic.com)에서 요청.
:::

:::danger 카드 정보는 절대 캡처해서 공유하지 마세요
당연한 얘기지만 신용카드 번호·CVC는 누구한테도 보여주면 안 됩니다. 카톡·이메일·블로그에 절대 X.

## 5. Claude Code가 뭐예요?

이게 진짜 마법입니다. 정신 차리고 읽으세요.

### 기존 AI 사용 방식

```
[ 내 컴퓨터 ]            [ 브라우저: Claude.ai ]
   index.html  ─복사→     "이 파일 색 바꿔줘"
   (수동)                       ↓
                          AI가 답 줌
   index.html  ←붙여넣기   (수동 복사)
```

매번 복붙. 파일 10개 고치려면 복붙 10번.

### Claude Code 방식

```
[ 내 컴퓨터 ]
   터미널 열고 "claude" 입력
        ↓
   "헤더 색깔 파란색으로 바꿔줘"
        ↓
   Claude가 직접:
     ✅ src/components/Header.tsx 파일을 읽음
     ✅ 색깔 부분을 찾음
     ✅ 파란색으로 수정
     ✅ 저장
        ↓
   "✓ Header.tsx 1곳 수정했습니다" 보고
```

**복붙이 없습니다.** AI가 내 컴퓨터의 파일을 직접 읽고 직접 고칩니다.

### 비유: 인테리어 업자

- **기존 AI** = 전화로 인테리어 상담받기. "이걸 어떻게 하면 좋을까요?" → 조언 받음 → 내가 직접 사람 불러 시공
- **Claude Code** = 인테리어 업자가 우리 집에 와서 직접 작업. 시키기만 하면 됨

## 6. Claude Code 설치

설치는 터미널에서 명령어 한 줄로 끝납니다.

### Step 1. 터미널 열기

| OS | 방법 |
|---|---|
| **Mac** | `Cmd + Space` → "터미널" 입력 → Enter |
| **Windows** | `Win 키` → "PowerShell" 입력 → Enter |

> 🤔 터미널이 뭐예요?
> 검은 화면에 글자로 컴퓨터한테 명령 내리는 곳입니다. 마우스 클릭 대신 키보드로 명령합니다. 자세한 건 6강(VS Code & 터미널)에서.

### Step 2. Node.js 먼저 확인

터미널에 입력:

```bash
node --version
```

| 결과 | 의미 |
|---|---|
| `v20.x.x` 같은 숫자 | ✅ Node.js 설치됨, 다음 단계로 |
| `command not found` | ❌ Node.js 없음. 아래 단계 |

**Node.js 없으면:**
1. [nodejs.org](https://nodejs.org) 접속
2. **LTS** (Long Term Support) 버전 클릭 → 다운로드
3. 설치 (다음→다음→완료)
4. **터미널을 닫고 새로 엽니다** (이게 중요!)
5. 다시 `node --version` → 버전 나오면 OK

### Step 3. Claude Code 설치

터미널에 한 줄:

```bash
npm install -g @anthropic-ai/claude-code
```

> 🤔 이 명령이 뭐예요?
> - `npm` = Node.js의 앱스토어
> - `install -g` = 전역(global)으로 설치 (어디서나 사용 가능)
> - `@anthropic-ai/claude-code` = 설치할 앱 이름

1~2분 대기. 진행상황 메시지가 줄줄이 뜹니다. 마지막에 새 줄로 돌아오면 완료.

### Step 4. 설치 확인

```bash
claude --version
```

→ `1.x.x` 같은 버전 번호 나오면 성공.

:::warning permission denied 에러가 나면?
**Mac**: `sudo npm install -g @anthropic-ai/claude-code` (sudo 추가)
→ 비밀번호 물어보면 맥 로그인 비밀번호 입력

**Windows**: PowerShell을 **관리자 권한**으로 다시 실행 (우클릭 → "관리자로 실행")
:::

## 7. 처음 실행 + 로그인

### Step 1. 실행

아무 폴더나 터미널에서:

```bash
claude
```

처음 실행하면:
1. 브라우저가 자동으로 열림
2. Claude 로그인 화면 표시
3. Pro 계정으로 로그인
4. "Authorize Claude Code" 같은 버튼 클릭 → 권한 허용
5. 터미널로 돌아옴
6. `>` 프롬프트가 보이면 준비 완료

### Step 2. 첫 대화

`>` 옆에 한국어로 입력:

```
안녕? 너 누구야?
```

Enter → Claude가 한국어로 자기소개. **성공!**

### Step 3. 종료 / 재실행

| 동작 | 명령 |
|---|---|
| 종료 | `Ctrl + C` 두 번 누름 |
| 재실행 | 터미널에 `claude` |
| 다른 폴더에서 사용 | `cd 폴더경로` → `claude` |

## 8. Claude Code 기본 사용법

### 원칙: 한국어로, 일상 언어로

```
❌ 나쁜 예 (전문 용어):
  "Header 컴포넌트의 backgroundColor 속성을
   tailwind의 bg-blue-500 클래스로 변경해줘"

✅ 좋은 예 (일상 언어):
  "헤더 색깔을 파란색으로 바꿔줘"
```

Claude가 알아서 전문 용어로 번역합니다.

### 자주 쓰는 명령 예시

| 하고 싶은 일 | Claude한테 하는 말 |
|---|---|
| 프로젝트 파악 | "이 프로젝트가 어떤 프로젝트인지 한국어로 설명해줘" |
| 파일 찾기 | "블로그 이름이 어디서 관리되는지 찾아줘" |
| 색깔 변경 | "메인 색을 진한 남색으로 바꿔줘" |
| 글자 변경 | "사이트 제목을 '나의 블로그'로 바꿔줘" |
| 에러 해결 | "이런 에러가 났어: [에러 내용 붙여넣기]. 고쳐줘" |
| 저장하기 | "방금 한 작업을 git 커밋하고 push해줘" |

### 승인(y/n) 받는 순간

Claude가 파일을 고치려고 할 때 **"이렇게 바꿔도 될까요?"** 물어봅니다.

```
Edit Header.tsx?
  - bg-white
  + bg-blue-500

Do you want to make this edit?
> 1. Yes
  2. No
```

- 괜찮으면 **`1` 또는 Enter** → 변경 적용
- 싫으면 **`2`** → 변경 안 함

:::tip 잘못 바꿨으면?
Claude한테 **"방금 한 작업을 되돌려줘"** 하면 git 명령으로 되돌립니다.
:::

## 9. 자주 묻는 질문

**Q1. Claude가 잘못 알아들으면?**
구체적으로 다시 말합니다. "헤더 색 바꿔줘" 대신 "헤더의 배경색만, 진한 남색(#1e3a8a)으로 바꿔줘".

**Q2. 토큰이 다 떨어졌다고 하면?**
Pro 플랜은 5시간마다 사용량이 리셋됩니다. 너무 많이 쓰면 일시 제한. 5시간 후 다시 가능.

**Q3. 오프라인에서도 쓸 수 있나요?**
아니요. Claude는 인터넷이 있어야 합니다. AI가 Anthropic 서버에서 동작합니다.

**Q4. 내 파일을 Anthropic이 본다는 거예요?**
Claude Code는 파일 내용을 Anthropic 서버로 전송해서 처리합니다. 비밀 파일(`.env` 같은)은 자동으로 제외되긴 하지만, 회사 기밀 같은 건 따로 보호 필요.

**Q5. 한국 카드로 결제 안 돼요.**
대부분 비자/마스터카드는 됩니다. 안 되면 페이팔 옵션도 있습니다. 그래도 안 되면 가상 신용카드 (트래블월렛 등) 사용 가능.
