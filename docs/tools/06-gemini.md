# 6강. Gemini — AI 글쓰기 비서

> **이 강의에서 배울 것**
> Gemini가 뭔지, '키워드만 주면 글 써주는' 게 어떻게 가능한지, 'API'·'API 키'라는 단어가 뭔지 이해합니다.

---

## Gemini가 뭐예요?

> 👉 **구글이 만든 AI. 우리 블로그에서 글을 자동으로 써주는 작가 알바.**

| 비유 | 실제 |
|---|---|
| 카페 메뉴 설명 쓰는 작가 알바 | Gemini |
| 작가에게 주는 키워드 | "강남 카페 추천", "다이어트 음식" 같은 주제어 |
| 작가가 써준 글 | 블로그 본문 |

---

## Claude vs Gemini — 왜 둘 다 써요?

| 항목 | Claude | Gemini |
|---|---|---|
| 만든 곳 | Anthropic | Google |
| 잘하는 것 | **코드 작성** | **글 작성** |
| 가격 | $20/월 (Pro) | API 무료 한도 있음 |
| 우리가 쓰는 용도 | 블로그 코드 만들기 | 블로그 글 만들기 |
| 사용 방식 | Claude Code (터미널) | API 키 + 코드 호출 |

> 💡 **Claude는 사람처럼 코드를 짜는 알바**, **Gemini는 자동으로 글을 생산하는 공장**.

---

## 핵심 용어 풀이

### 1. API (Application Programming Interface)
> "프로그램끼리 대화하는 약속."

비유: 식당의 **종업원**.
- 손님 (= 우리 블로그 코드): "김치찌개 하나 주세요"
- 종업원 (= API): 주방에 전달
- 주방 (= Gemini AI): 만들어서 줌
- 종업원이 손님에게 가져다 줌

API는 **'어떤 형식으로 요청하면 어떤 형식으로 답해줄지'** 정해진 규칙.

### 2. API 키 (API Key)
> "API를 쓸 때 보여주는 출입증."

비유: 헬스장 회원증.
- 회원증 있으면 운동 기구 사용 가능
- API 키 있으면 Gemini AI에게 요청 가능

```
AIzaSyA-1234-내Gemini-API-키-예시-문자열
```

> ⚠️ **API 키도 GitHub에 절대 안 올림.** 환경변수에만.

### 3. 토큰 (LLM 토큰) — Turso 토큰과 다름!
> "AI가 글을 처리할 때 세는 단위. 대략 한국어 1글자 ≈ 1~2 토큰."

| 비유 | 토큰 |
|---|---|
| "안녕하세요" | 약 5~10 토큰 |
| 블로그 글 1편 (1000자) | 약 1,500~2,000 토큰 |
| 종이책 1권 | 약 10만 토큰 |

Gemini 무료 한도: 분당 토큰 수 제한 있음 (그래도 블로그 운영엔 충분).

### 4. 프롬프트 (Prompt)
> "AI에게 시키는 명령문."

예시 프롬프트:
```
"강남 카페 추천 글을 1500자로 써줘.
대상: 20대 여성.
톤: 친근하고 정보 많은.
포함: 가게 이름 5개, 가격대, 분위기."
```

좋은 프롬프트 = 좋은 결과.

### 5. LLM (Large Language Model, 거대 언어 모델)
> "엄청 많은 텍스트로 학습한 AI."

Gemini·Claude·ChatGPT 모두 LLM. **인터넷의 거의 모든 글을 읽고 학습** → 어떤 주제든 글 작성 가능.

## 작동 흐름

```
   내가 키워드 입력
   "강남 카페 추천"
          ↓
   ┌──────────────────┐
   │  내 블로그 코드    │
   │  (Vercel에서 실행) │
   └────────┬─────────┘
            │ API 호출
            │ (키 + 프롬프트 전송)
            ▼
   ┌──────────────────┐
   │   Google Gemini   │  ← AI 글 생성
   └────────┬─────────┘
            │ 글 반환 (1500자)
            ▼
   ┌──────────────────┐
   │  Turso DB 저장    │
   └────────┬─────────┘
            ▼
   ┌──────────────────┐
   │  블로그에 글 게시  │
   └──────────────────┘

   소요 시간: 10~30초 / 1편
```

## 자주 묻는 질문

**Q. Gemini 말고 GPT나 Claude로 글 써도 되나요?**
- 가능. 단, 둘 다 유료 API.
- Gemini는 무료 한도가 커서 입문에 좋음.

**Q. AI 글이 표절 아닌가요?**
- LLM은 기존 글을 **복사**하지 않고 **새로 작성**. 표절은 아님.
- 다만 사실 확인은 본인이 해야 함 (AI도 틀리는 경우 있음).

**Q. 카드 없이 가입 가능?**
- 무료 한도 내에서는 카드 없이 가능.

**Q. 한국어 잘 써요?**
- 매우 잘 함. 자연스러움.

**Q. AI 글로 구글 검색 상위 가능?**
- 가능. 단, 사람이 검수·보완하면 더 좋음.
- 이 방법으로 월 수십만 원 광고 수익 내는 사례 많음.
