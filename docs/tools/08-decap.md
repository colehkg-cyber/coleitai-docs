# 8강. Decap CMS — 블로그 글쓰기 화면

> **이 강의에서 배울 것**
> '/admin'을 입력하면 나오는 글쓰기 화면이 뭔지, CMS·Headless CMS가 뭔지, 워드프레스와 어떻게 다른지 이해합니다.

---

## Decap CMS가 뭐예요?

> 👉 **블로그 주소 끝에 `/admin`을 붙이면 나오는, 워드프레스 같은 글쓰기 화면.**

| 비유 | 실제 |
|---|---|
| 카페 POS 단말기 (주문 입력기) | Decap CMS |
| POS에 메뉴 추가 | 블로그에 새 글 작성 |
| POS 백오피스 (사장님 화면) | /admin 페이지 |

쉽게 말해 **"코드 몰라도 글 쓸 수 있게 해주는 GUI"**.

---

## 왜 필요한가요?

블로그 글은 어디 저장될까요? 답: **GitHub에 `.md` 파일로**.

그럼 글 쓸 때마다:
- ❌ VS Code 열고 → 파일 만들고 → git push → 불편
- ✅ `/admin` 들어가서 → 워드프레스처럼 글 쓰고 → "Publish" 클릭 → 끝

Decap CMS = **GitHub에 자동으로 .md 파일을 만들어 주는 글쓰기 UI**.

---

## 핵심 용어 풀이

### 1. CMS (Content Management System)
> "콘텐츠(글·이미지) 관리 시스템."

대표 CMS:
| CMS | 특징 |
|---|---|
| **워드프레스** | 가장 유명. 서버 필요. |
| **Decap CMS** | 우리 사용. GitHub 직접 사용. 무료. |
| Strapi | 개발자용. 강력. |
| Contentful | 유료 클라우드 CMS. |

### 2. Headless CMS
> "데이터(글)는 따로, 보여주는 화면은 따로 만드는 방식."

| 방식 | 글 저장 | 화면 |
|---|---|---|
| 전통 CMS (워드프레스) | DB에 글 + 화면도 같이 | 하나의 덩어리 |
| Headless CMS | 글은 GitHub에 .md | 화면은 Next.js로 자유롭게 |

**장점**: 화면 디자인을 코드로 100% 마음대로 만들 수 있음.

### 3. /admin 페이지
> "블로그 주소 끝에 /admin 붙이면 나오는 관리자 화면."

예: `https://myblog.vercel.app/admin`

여기서:
- 새 글 작성
- 기존 글 수정·삭제
- 이미지 업로드
- 카테고리 관리

### 4. 마크다운 (Markdown, .md)
> "글 형식을 간단한 기호로 표현하는 문법."

| 마크다운 | 결과 |
|---|---|
| `# 제목` | 큰 제목 |
| `## 소제목` | 중간 제목 |
| `**굵게**` | **굵게** |
| `[링크](url)` | 링크 |
| `![이미지](url)` | 이미지 |

Decap CMS는 워드프레스처럼 버튼으로 표시해도, **저장은 .md 파일**로.

### 5. 프론트매터 (Frontmatter)
> ".md 파일 맨 위에 적는 메타정보."

예시:
```markdown
---
title: "강남 카페 추천 BEST 5"
date: 2024-05-13
category: "맛집"
tags: ["강남", "카페"]
---

# 본문 시작
오늘은 강남에 가볼만한...
```

Decap CMS는 이 부분을 **양식 입력란**으로 자동 변환해 줍니다.

---

## 작동 흐름

```
   사장님이 /admin 접속
          ↓
   ┌──────────────────────┐
   │  Decap CMS 글쓰기 화면  │
   │  (제목·본문·이미지 입력) │
   └────────┬─────────────┘
            │ "Publish" 클릭
            ▼
   ┌──────────────────────┐
   │  GitHub에 .md 파일 추가 │
   │  자동 커밋             │
   └────────┬─────────────┘
            │ 자동 감지
            ▼
   ┌──────────────────────┐
   │  Vercel 자동 빌드      │
   └────────┬─────────────┘
            ▼
   ┌──────────────────────┐
   │  블로그에 새 글 공개    │
   └──────────────────────┘

   소요 시간: 1분 안에 글 공개
```

## 워드프레스 vs Decap CMS

| 항목 | 워드프레스 | Decap CMS |
|---|---|---|
| 비용 | 서버 월 1~5만원 | 무료 |
| 속도 | 느림 | 빠름 (정적 빌드) |
| 보안 | 해킹 위험 (플러그인) | 안전 (GitHub 기반) |
| 글 저장 | DB | GitHub .md 파일 |
| 백업 | 별도 작업 | 자동 (GitHub 이력) |
| 디자인 자유도 | 테마 안에서 | 코드 100% 자유 |
| 진입장벽 | 낮음 | 살짝 높음 (가입 7개) |

## Decap CMS 가입은 안 해도 되나요?

> 👉 **Decap CMS 자체는 가입 없음.** GitHub 계정만 있으면 됨.

`/admin` 들어가면 "GitHub로 로그인" 버튼 → 끝.

## 자주 묻는 질문

**Q. 워드프레스 익숙한데 굳이 바꿔야 하나요?**
- 워드프레스도 좋습니다.
- 이 책의 목표는 **"개발자 없이 빠른 블로그"** → Decap이 더 적합.

**Q. 글 잘못 발행하면 되돌릴 수 있나요?**
- GitHub 이력에서 1초 복구. 워드프레스보다 안전.

**Q. 이미지 업로드는?**
- Decap에서 드래그&드롭 → GitHub에 자동 저장.

**Q. 글 쓰는 게 어렵나요?**
- 워드프레스랑 비슷. 5분이면 익숙해짐.

**Q. 모바일에서 글 쓸 수 있나요?**
- 가능. 모바일 브라우저로 /admin 접속.
