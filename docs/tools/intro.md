# 도구 알아보기 — 시작하기

> **이 섹션의 목적**
> 우리가 블로그를 만들 때 사용하는 **7가지 도구**가 각각 무엇이고, 왜 필요하고, 어떻게 동작하는지 이해합니다.
> **결과물**: "이 도구가 카페로 치면 뭐다" 라고 한 줄로 말할 수 있게 됩니다.

---

## 왜 도구부터 공부하나요?

블로그 코드를 다운로드 받고 → 인터넷에 올리는 그 과정에서 **계정 7개, 키 5개, 명령어 10여 개**를 만나게 됩니다.

"무슨 일이 일어나는지 모른 채" 따라 하면, 에러 한 번에 막혀버립니다.
그래서 실습 들어가기 전에, **도구 하나하나를 카페·도서관·매장에 비유해서** 이해해 둡니다.

이해만 하면 됩니다. 가입·결제·설치 같은 실제 작업은 다음 섹션 **🚀 실전 블로그 제작** 에서 한꺼번에 합니다.

---

## 우리가 쓸 7가지 도구

| # | 도구 | 카페로 치면 | 한 줄 정의 | 비용 |
|---|---|---|---|---|
| 1 | **Claude** | 똑똑한 알바생 | AI가 내 컴퓨터에서 직접 코드 작성 | $20/월 |
| 2 | **GitHub** | 레시피 노트(이력 보관) | 코드 저장소 + 변경 이력 추적 | 무료 |
| 3 | **Vercel** | 카페 매장 | 코드 → 인터넷에 자동 공개 | 무료 |
| 4 | **Turso** | 매출 장부 | 블로그 글·조회수 저장 DB | 무료 |
| 5 | **Gemini** | 글쓰기 비서 | AI 글 생성기 (블로그 글 자동 작성) | 무료 |
| 6 | **VS Code** | 카페 주방(작업대) | 코드를 보고 수정하는 편집기 | 무료 |
| 7 | **Decap CMS** | 카페 POS기 | 블로그에서 글 쓰는 화면 | 무료 |

> 💡 **돈 드는 건 Claude Pro 딱 1개.** 나머지 6개는 평생 무료로 충분합니다.

---

## 학습 순서

각 도구마다 1챕터씩, 다음 순서로 읽어 주세요.

```
1강 한눈에 보기 (전체 흐름 도식)
    ↓
2강 Claude — AI 알바생
    ↓
3강 GitHub — 코드 도서관
    ↓
4강 Vercel — 인터넷 매장
    ↓
5강 Turso — 글 저장 DB
    ↓
6강 Gemini — AI 글쓰기 비서
    ↓
7강 VS Code & 터미널 — 작업 환경
    ↓
8강 Decap CMS — 블로그 글쓰기 화면
```
