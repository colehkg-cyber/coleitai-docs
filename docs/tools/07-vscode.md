# 7강. VS Code & 터미널 — 작업 환경

> **이 강의에서 배울 것**
> '코드 편집기'가 뭔지, '터미널'에서 까만 화면에 글자 쳐서 명령하는 게 뭔지, Node.js·npm이 뭔지 이해합니다.

---

## VS Code가 뭐예요?

> 👉 **Microsoft가 만든 무료 코드 편집기. 전 세계 개발자 70% 이상이 사용.**

| 비유 | 실제 |
|---|---|
| 카페 주방 (조리·정리하는 공간) | VS Code |
| 도마·칼·후라이팬 | 편집기 안 기능들 |
| 음식 (= 코드) | 우리가 작업할 결과물 |

쉽게 말해 **"문서 워드 + 개발자 기능"**.

## 핵심 용어 풀이

### 1. 편집기 (Editor / IDE)
> "코드를 쓰고 수정하는 프로그램."

종류:
- **VS Code** (우리 사용) — 무료, 가장 인기
- Cursor — VS Code 기반 + AI 강화
- WebStorm — 유료, 강력
- Sublime Text — 가볍지만 유료

### 2. 터미널 (Terminal)
> "까만 화면에 글자 쳐서 컴퓨터에 명령하는 도구."

비유: 식당 인터폰. 종업원(GUI)에게 말로 시키는 대신, 주방장(컴퓨터)에게 직접 명령.

예시 명령:
```bash
ls                 # 현재 폴더의 파일 목록 보기
cd Documents       # Documents 폴더로 이동
npm install        # 프로젝트 부품 설치
git push           # GitHub에 코드 업로드
```

VS Code 안에 터미널이 내장되어 있어요. **Ctrl + `** (백틱) 키.

### 3. 명령어 (Command)
> "터미널에 입력하는 짧은 영어 단어."

| 명령어 | 의미 |
|---|---|
| `ls` | list — 파일 목록 |
| `cd` | change directory — 폴더 이동 |
| `mkdir` | make directory — 폴더 생성 |
| `rm` | remove — 파일 삭제 |
| `cat` | concatenate — 파일 내용 출력 |

당장 외울 필요 없음. Claude가 알려줍니다.

### 4. Node.js
> "JavaScript를 내 컴퓨터에서 실행시켜주는 프로그램."

비유: 영어책을 한국어로 번역해주는 통역사.
- JavaScript = 원래 브라우저에서만 돌아가는 언어
- Node.js = JavaScript를 컴퓨터에서도 돌아가게 함

우리 블로그 (Next.js)는 Node.js 위에서 동작.

### 5. npm (Node Package Manager)
> "Node.js용 부품(라이브러리) 다운로드 도구."

비유: 앱스토어.
- 앱스토어 = 앱 모음
- npm = 코드 부품 모음 (200만 개 이상)

예시:
```bash
npm install next        # Next.js 부품 설치
npm install @anthropic-ai/claude-code  # Claude Code 설치
```

### 6. package.json
> "이 프로젝트에 어떤 부품이 필요한지 적은 명세서."

```json
{
  "name": "my-blog",
  "dependencies": {
    "next": "14.0.0",
    "react": "18.2.0"
  }
}
```

`npm install` 하면 → 이 파일 보고 → 필요한 부품 다 다운로드.

### 7. node_modules
> "npm install로 다운받은 부품들이 쌓이는 폴더."

용량 매우 큼 (수 GB). GitHub에 절대 올리지 않음 (`.gitignore`에 포함됨).

## VS Code 화면 구조

```
┌──────────────────────────────────────────┐
│ [파일 메뉴]                               │
├──────┬───────────────────────────────────┤
│      │                                   │
│파일  │      코드 편집 영역                  │
│탐색기 │  (실제로 코드 쓰는 곳)              │
│      │                                   │
│      │                                   │
├──────┴───────────────────────────────────┤
│  터미널 (Ctrl + ` 로 토글)                 │
└──────────────────────────────────────────┘
```

- 왼쪽: 파일 목록
- 가운데: 코드
- 아래: 터미널

## Claude Code와의 관계

```
   VS Code (편집기 + 터미널)
        │
        ├─ 코드 보기·수정 (사람)
        │
        └─ 터미널에서 'claude' 명령 실행
                │
                ▼
           Claude Code 실행
                │
                ▼
           AI가 코드를 직접 읽고 고침
```

→ VS Code는 **무대**, Claude Code는 **AI 알바**, 사람은 **감독**.

## 자주 묻는 질문

**Q. VS Code 말고 Cursor 써도 되나요?**
- 가능. Cursor는 VS Code + AI 통합.
- 우리는 VS Code + Claude Code 조합. 둘 다 유효.

**Q. 터미널 무서워요.**
- 처음엔 다 무섭습니다. 5개 명령만 외우면 90% 처리 가능.
- 명령 잘못 쳐도 컴퓨터 안 망가짐. 안전.

**Q. Mac과 Windows 터미널이 달라요?**
- 약간 다름. Mac은 zsh, Windows는 PowerShell.
- 우리가 쓸 명령(`git`, `npm`, `claude`)은 둘 다 동일하게 동작.

**Q. Node.js 버전이 여러 개라고 들었어요.**
- LTS 버전(짝수)만 쓰면 OK. 우리는 Node 20.x 이상 권장.
